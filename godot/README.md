# Urbs Labyrinthi — Godot 版(ハックアンドスラッシュ試作)

`docs/roadmap-fvtt-hackslash.md` §3 の段0〜4を、Godot 4(4.7.2 で確認)で一通り動かしたもの。
迷宮の中身(部屋、通路、扉、罠、遭遇、宝)は、`docs/urbs-labyrinthi.html` の生成器 `Core` が決めた JSON を読んで作る。
ゲーム側は生成のしかたを知らないので、生成器を直して JSON を書き出し直せば、そのまま遊びが変わる。

## 遊び方

Godot 4 で `godot/project.godot` を開いて実行する(初回は、フォントの取り込みが走る)。

| 操作 | キー |
|---|---|
| 移動 | WASD / 矢印 |
| 攻撃 | Space / J / 左クリック(クリックは、マウスの向きへ振る) |
| 転がり(無敵つき) | Shift / K |
| 調べる(宝、解錠、罠の解除、階段) | E |
| 探る(近くの隠し扉と罠を判定で探す) | F |
| 治療薬 | Q |
| クレジット(SRD の帰属表示) | F1 |

**遊びの流れ**: 第1層から潜る → 燐晶(宝箱)を集める → 第1層の上り階段から地上へ戻る → 3割が燐晶税として引かれ、残りが預け金になる → 次の夜に潜る(通路が組み替わる)。力尽きると、未査定の燐晶を失う(預け金は残る)。

**出てくるもの**
- 層 1〜10。舞台は層で変わる(腐葉の回廊、錆鉄の坑道、鏡の水廊、骨の大聖堂、第10層以降は未踏・仮)
- 霧と視界(見たところは薄暗く残る)。灯りのある部屋は、入ると全体が見える
- 扉(開口、扉、施錠、隠し)。隠し扉と罠は、受動〈知覚〉で近づくと気づくか、F で探る
- 魔物は SRD の能力値のまま持つ。頭は三種(mindless / beast / smart)。群れで動き、傷が深いと逃げる。態度が「警戒」は近づくまで、「交渉の余地あり」は手を出すまで動かない
- 罠はセーヴ、攻撃ロール、警報。難易度とダメージは SRD の表のまま
- 夜は14夜ぶんを書き出してある。吐く夜(第三節、第五節の夜)は遭遇が増える
- レベルは SRD の経験点表で上がる

## 数値の置き換え(`scripts/balance.gd`)

| SRD | ここでの扱い |
|---|---|
| HP、ダメージ式、脅威度、XP | そのまま |
| AC | 被ダメージの軽減率 (AC−10)×3%、最大45%(展開メモ §3.2 案1) |
| 攻撃ボーナス | 使わない(当たりは見た目で決まる)。罠の攻撃ロールには使う |
| 移動速度 | 1フィート/ラウンド = 4画素/秒(30フィートで秒速120画素。プレイヤーは150) |
| 1ラウンド6秒のダメージ | 敵は ×0.4 を、1.6秒おきに(`ENEMY_DMG_SCALE`)。罠は ×0.6 |
| 複数回攻撃 | 一度の攻撃で2回続けて当てる |
| 特徴(Pack Tactics など) | 名前しか持っていないので未対応 |

## データの作り直し

```sh
node tools/export-floors.mjs            # godot/data/ に 10層 × 14夜 を書き出す(種 vergha)
node tools/export-floors.mjs godot/data 別の種 14 10
```

`docs/urbs-labyrinthi.html` の `Core` を Node で動かして、層ごとの JSON を書く(ソロ用に人数1)。
遭遇の予算は、層の舞台の想定レベル(1, 3, 5, 9, 15)で組んである。

## 確認

```sh
godot --headless --path godot -s res://tests/smoke_test.gd        # ダイス、全140層の連結、潜る・戦う・罠・地上・死亡
xvfb-run -a godot --path godot --rendering-driver opengl3 -s res://tests/screenshot.gd -- /tmp 3   # 第3層を撮る
```

## ファイル

| 場所 | 役目 |
|---|---|
| `scripts/floor_map.gd` | JSON → 地図。衝突、視界(直線の見通し)、魔物の経路(幅優先の距離場) |
| `scripts/floor_instance.gd` | 1層の状態(魔物、宝箱、罠)と床の描画。層を離れても控えておく |
| `scripts/enemy.gd` / `projectile.gd` | 魔物の頭と攻撃 |
| `scripts/player.gd` | 移動、斬撃、転がり |
| `scripts/main.gd` | 規則(罠、解錠、宝、階段、査定、夜の巡り) |
| `scripts/hud.gd` | 表示(HP、ログ、小さな地図、報告) |
| `scripts/balance.gd` | 調整する数値 |
| `data/floors/` | 書き出した層(`fNN_nMM.json` = 第NN層、第MM夜) |

## 書き出し(エクスポート)するとき

`data/floors/*.json` は、リソースではなく生のファイルとして読んでいる。エクスポートの「リソース」タブの「非リソースのファイルを書き出すフィルター」に `data/*, data/floors/*` を入れる。

## 分かっている限界

- 生成器は JavaScript のまま(JSON を読む方式)。夜は14夜で一巡する。ゲーム内で無限に作りたくなったら、生成器を GDScript に移す(展開メモ §3.3。乱数は xmur3 / mulberry32 を同じ式で、引く順番も変えない)
- 通路は幅1マスのまま。広げる案(展開メモ §3.1)は未着手
- 第10層の先は無い。探索の進み具合の保存も無い
- 魔物の特徴(Pack Tactics、再生、耐性など)と状態異常(毒、拘束、恐怖)は未対応。罠の効果文は、ダメージだけを反映する
- 「交渉の余地あり」の魔物と話す手段は無い(手を出すまで動かないだけ)
- 音と効果音は無い。固定の画面比(16:9)で作ってある
