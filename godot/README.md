# Urbs Labyrinthi — Godot 版(ハックアンドスラッシュ)

迷宮都市ヴェルガ・ノクスを舞台にした、体当たりで押し合うアクションRPG(Godot 4.7.2 で確認)。
迷宮の中身(部屋、通路、扉、罠、遭遇、宝)は、`docs/urbs-labyrinthi.html` の生成器 `Core` が決めた JSON を読んで作る。
ゲーム側は生成のしかたを知らないので、生成器を直して JSON を書き出し直せば、そのまま遊びが変わる。

ビルド済みの実行ファイルは、リポジトリ直下の [`Deploy/`](../Deploy/README.md) にある(Linux、Windows)。

## 遊びの流れ

タイトル → **キャラ作成**(始めは二人。宿屋の酒場で最大4人まで増やせる) → **街**(店、神殿、宿) → 迷宮 → 燐晶を持って街へ → 次の夜、の繰り返し。

- 街へ戻ると、持ち帰った燐晶の3割が税になり、残りが預け金(銀貨)になる。預け金で装備や薬、呪文書を買う。
- 迷宮の通路は、毎夜組み替わる(縦穴、階段の候補地、骨組みの道と大部屋は同じ場所。階段は候補地を夜ごとに巡り、一画の通路と小部屋は静かな夜に4割、吐く夜に全部が組み替わる)。7夜で一巡する。
- 全滅すると、未査定の燐晶と、持ち物と装備(武器・防具も)を全部失う(預け金は残る)。個別に倒れた仲間は、神殿で蘇らせる。
- 第三節と第五節の夜は「吐く夜」。その日の迷宮で日が落ちると、迷宮が魔物を大量に吐き出し(群れが5組、その後もワンダリングが4倍出やすく、上限10組)、夜明けまで階段が塞がる。ほかの夜と違い、吐息に呑まれて放り出されはしない。
- 宿屋でセーブできる。街へ着くたびに自動でもセーブされる。
- 迷宮の中でも、持ち物の画面(Tab)の「記録をつける」でセーブできる。タイトルの「つづきから」で、その層のその場所から再開する(見た範囲、扉、罠、落ちているもの、生きている魔物、袋の燐晶、迷宮の時刻も戻る)。迷宮の記録は `user://dive.sav` で、街へ戻るか、全滅するか、次の夜に潜ると消える(`scripts/dive_save.gd`)。
- 料理: 持ち物の画面の「料理」。迷宮の中では、燃料(焚き木束・焼け石・白蝋)で火を熾し、野営の料理を作る(1回20分。火は1時間もつ)。出来ばえは料理番(〈生存〉がいちばん高い人)の d20 で、上出来・ふつう・焦げた。食材は迷宮の自生物と魔物の素材、街の市場「灰の辻」で買う品。レシピは45(野営26、自宅の台所19)。中身は `data/cooking.json`、仕組みは `scripts/cooking.gd`。
- 満腹度は一人ずつ(0〜100)。迷宮で起きていると16時間で空になる(休むと3分の1の速さ)。30未満で空腹(頭上で「ぐぅ〜」)、10未満で腹ぺこ(力 -10%、足 -5%)。潜るときは満腹80から。料理を食べると満腹が増え、ささやかな効き目(一人一つ。力、守り、足、呪、体、魔、灯、目、手、息吹、寒さ除け、毒除け、腹持ち、寝つき)が数時間つく。料理には日持ちがあり、過ぎると「くさった○○」になる(食べると腹を下す)。
- 自宅: 坑口館の「空き家の札」で、壁下区の長屋の一間を買う(2000銀貨)。買うと広場に看板「我が家」が出る。はじめは台所(全部の料理を、燃料なしで作れる)と寝床(ただで全快、記録もつけられる)。増築で食料庫(料理の傷む速さが4分の1、600)、物置(預けたものは全滅しても失わない、400)、実験室(1500)、鍛冶場(1800)。仕組みは `scripts/home.gd`、画面は `scripts/home_panel.gd`。
- 鍛冶(鍛冶場): 炉火の槌の武具(魔法の腕輪・長靴を除く)は全部作れる。金物は鉄塊(値段100銀貨ごとに1つ)、革鎧は獣皮、弓は弓材と羽。魔物の素材からだけ作れる品が6つ(牙の短剣、骨の長弓、燐晶嵌めの鎚、鱗の胴着、錆苔焼きの胸甲、獣皮の外套)。鉄塊・炭・弓材は炉火の槌で売り、鉄屑3つを溶かしても鉄塊になる。1回に炭か焼け石を1つ。鍛冶役は【筋力】の補正(戦士・蛮族は習熟も)が高い人で、d20 が難しさ +5 で良品(武器の威力 +0.5、防具の防御 +1)、+10 か出目20で逸品(+1.0 / +2)、届かないと材料の半分を失う。重い鎧は金床で一夜冷ます。良品・逸品は `<id>+1` `<id>+2` という別の品として ItemDB に入る。中身は `data/smithing.json`、仕組みは `scripts/smithing.gd`。
- 魔法実験(実験室): 15のレシピ(`data/alchemy.json`)。治療薬・毒消し・眠り瓶などはすぐできる調合、力の水薬や再生の霊薬などは釜に仕込んで1〜5夜寝かせる(釜は3つ、迷宮から戻るたびに1夜)。1回に燃料を1つ。実験役(〈魔法学〉がいちばん高い人)の d20 で、上出来は1つ多く、難しさに届かないと濁った薬、出目1は「ボフン!」で材料を失い、その夜は実験室が使えない。

## 操作

初期設定。タイトルか街の「操作の設定」で、キー2つとコントローラーの入力1つを、操作ごとに変えられる(`user://controls.cfg` に保存)。

## 攻撃と押し合い(ハイドライド式)

**攻撃はボタンで正面へ一撃**(剣なら左右 70° の扇、体の縁から 22px。武器の種類で変わる。下の表)。振ったあとは待ち時間(0.5秒)があり、下のスキルの段の左端と、操作中の仲間の足もとの棒で進み具合が分かる。仲間の体当たりではダメージは入らない。
**魔物は、触れている間は自動で殴ってくる**(押し込むほど有利。背を向けて離れようとしている間だけ、殴らない)。

- **すり抜け**: 仲間どうしは、動いている間すり抜ける。止まると、先頭の通った跡に沿って後ろへ並び、止まっている者どうしはゆっくり離れる。話し合える魔物(中立)も、すり抜ける。
- **壁の角**: 幅1マスの通路の入口で、角に少し掛かっていても、通れる側へ滑って入る(`FloorMap.slide_circle`)。

- **押し合い**: 互いの「押す力」(足の速さ × HP割合 × 重さ)の差で、境目が動く。
  **敵のHPが削れると、少しずつ押していける。こちらのHPが削られると、押される。** 壁際に押しつけられると、それ以上は下がれない。
- **重ならない**: 仲間と魔物、魔物どうしは、体が重ならない(`scripts/contact.gd`)。魔物どうしは、重さに応じて押しのけ合う。
- **溜め**: 攻撃を押した瞬間にふつうに一度振り、そのまま押し続けると溜まる(0.2秒後から、0.9秒で溜めきり。溜めきると「キン」)。離すと溜めの一撃(1.6〜3.0倍、届く距離1.3倍、押し返し2.2倍)。溜めている間は、足が0.6倍になる。構えは無くした。
- 大きな魔物ほど重く、押し負けやすい。「突進」「薙ぎ払い」「聖撃」などは、敵を弾き飛ばして間合いを作る。
- 防具の防御は、被ダメージの軽減率(1点 3.5%、最大60%)。魔物の AC は 1点 3%、最大45%。

### 冒険日記帳と実績

持ち物の画面(Tab)の「冒険日記帳」と「実績」。記録は `gs.journal`(セーブに入る。`scripts/journal.gd`、`scripts/trophies.gd`)。確かめるのは `tests/journal_test.gd`。

- **冒険日記帳**: 層ごとに、その層に出る魔物を並べる(見かけていなければ ？？？)。選ぶと、種別・大きさ・脅威度・HP・AC、見かけた回数と倒した数、初めて出会った日と層、出る層、特徴の覚え書き(群れで囲む、など)。層の一覧に無い魔物(遺体から湧いた、など)は最後にまとめる。闘技場の魔物は数えない。新しい種類を見かけると「サラサラ」とログ。
- 層ごとの魔物の一覧は `data/bestiary.json`。層のデータを書き出し直したら `python3 tools/export-bestiary.py` で作り直す。
- **実績**: 30個。初めての獲物・百の骸・千の骸、見聞(25種・100種)、深さ(第3・5・7・10層)、Lv5・Lv10、四人の一行、燐晶長者(一度に1000銀貨)、灯手隊の世話(全滅)、料理(上出来・焦げ・くさったもの)、我が家、会心の調合、逸品、宝箱に噛まれた、層ごとの狩り尽くし(魔物の顔ぶれが同じ第1層と第2層は一つ)。取ると「パンパカパーン!」。

| 突進(Charge、Trampling Charge、Pounce)・跳躍(Standing Leap) | 70〜190px 離れていると、0.45秒構えて(「!」と「ドドドッ」)まっすぐ突っ込む。当たると1.5倍で弾き飛ばし(「ドカッ!」)、踏みつけ・飛びかかりは転ばせる。転がればかわせる。4〜6秒に一度。跳躍は構えが短く(「ピョン」)、弾くだけ |

スキルの `elem`: 火球 fire、聖撃 radiant、氷結 cold、雷光 lightning。

### 武器の種類と武器の技

通常攻撃の振り方は、武器の種類で変わる(`balance.gd` の `SWING`。数字は仮)。スキルの欄には「武器の技」が1つあり、持っている武器の種類で技が変わる。クラスの得意武器(戦士=剣、蛮族=斧、盗賊=短剣、魔術師=杖、僧侶=鈍器、野伏=弓)なら技の威力が1.3倍。

| 種類 | 振り方 | 武器の技 |
|---|---|---|
| 剣 | 標準 | 回転斬り(周りをまとめて斬る) |
| 短剣 | 届く距離が短く、待ち時間も短い(連打) | 二連突き |
| 斧 | 待ち時間が長く、一撃が重い | 叩き割り(6秒間、受けるダメージ1.3倍) |
| 鈍器 | 押し返しが強く、たまに怯ませる | 気絶打ち(1.5秒) |
| 槍 | 遠くまで届く突き。横は狭い | 突き通し(一列を遠くまで) |
| 杖 | 弱い | 魔力の溜め(8秒間、呪文1.4倍) |
| 弓 | 近くでは弱い | 狙い撃ち(貫く矢) |

珍しい武器(店に無く、遺体からまれに出る)は固有の技を持つ: 影縫いの短剣「影縫い」、坑夫の大鶴嘴「大地割り」、流星の槍「流星投げ」。

## 遺体

- 先に潜って戻らなかった者たちの遺体が、層のあちこちにある。**遺体をこうした魔物**(層でいちばん近い遭遇の魔物)で、見た目が変わる。
  - 食い荒らされた骨: 獣、怪物、竜、群れ、粘体、グール
  - 吊るされた体: 人型、悪魔、巨人。柱と腕木の吊り台から縄で吊られた体を、横から見た絵
  - 座って息絶えた体: それ以外
- 触れても何も起きない。**そばで E を押すと調べる**。持ち物(燐晶、遺品、薬、まれに装備)が散らばり、**遺体をこうした魔物が湧く**(仲間の人数−1 体まで)。調べた遺体は暗くなり、二度目は湧かない。

## 罠

- 罠は踏むと発動する。**魔物も踏む**(マスを移ったとき)。「探る(F)」や受動〈知覚〉で見つけると、赤い印が出る。
- **見つけた罠の前で E**: 3つから選ぶ(選んでいる間は止まる。Esc でやめる)。
  - **解除する**: いちばん得意な仲間の盗賊道具で判定。大きく外す(難易度−5以下)と発動する。
  - **わざと発動させる**: 石を投げて発動させる。物音で近く(8マス、警報の罠は14マス)の魔物が気づく。予兆のない罠は空撃ちで、だれも傷つかない。**予兆のある罠は本当に動く**(離れていれば無事。巻き込まれる範囲の魔物には当たる)。召喚の罠は魔物を呼ぶ。
  - **飛び越える**: 操作中の仲間の〈軽業〉か〈運動〉で判定(難易度 軽度10 / 危険13 / 致命的16)。成功すると6秒の間、一行は踏んでも発動しない(罠は残る)。失敗すると踏む。
- 罠の動きは、生成器の罠表の `fx` が決める(全73種、舞台ごとに名前と文面が違う)。ゲームの側は `scripts/trap_fx.gd` と `main.gd` の `_trigger_trap`。
- **予兆のある罠**(セーヴを振らない。そのとき範囲にいたかどうかで決まる。転がりの無敵の間は当たらない。魔物も巻き込む)
  - 爆発(爆ぜ茸、置き忘れの発破、泡立つ燃え水、爆ぜる光、爆発の罠): カチッ → 0.8秒の導火(赤い円) → **どかーーーーん!** 半径2.5マスを吹き飛ばし、画面が揺れる。落ちている燐晶や自生物は焼ける。
  - 飛び出す棘(槍衾、水底の棘、骨の棘床、棘の床): 0.5秒後にジャキン。すぐ離れれば当たらない。
  - 転がる大岩(暴走する鉱車、転がる岩): ゴロゴロゴロ… 罠のマスを通るまっすぐな床の、遠い端から転がってきて、轢いた者をドガッと横へはね飛ばす。
  - 崩れる天井(根に吊られた天井、朽ちた支保工、崩れる骨のアーチ、崩れる天井): ミシッと影が出て0.7秒後にガラガラッ。瓦礫は20秒、足が遅くなる。
  - 落ちる丸太・吊り灯: 影のあとドスン、真下の者を転ばせる。吊り香炉はガシャンと落ち、燃えさしが8秒くすぶる。
  - 火を吐く像(火を噴く像): 近くの壁から扇形の炎(ゴォォッ)を2秒。横へ回れば当たらない。
  - 矢(毒の吹き矢、毒矢、仕掛け弩): 近くの壁から、踏んだ者へ矢が飛ぶ(ヒュッヒュッ)。転がりでかわせる。毒矢は当たると毒。
  - 迫る壁(締まる坑木、迫る肋骨、迫る壁): ゴゴゴゴ… 2.2秒後に、部屋の壁ぎわ1マスにいる者が挟まれる(ドゴォン!)。
  - 網(絡みつく根、落ちる網): 0.35秒後にバサッ。網の下の者は3秒動けない(攻撃の連打で早く抜ける)。鈴で魔物が気づく。
  - 眠りの煙(眠り茸の胞子、眠りの淵、睡眠ガス): シュー… 5秒残る煙。中にいると毎秒【耐久力】セーヴ、失敗すると3秒眠る。冷たい霧は足が遅くなる。
- **ずっと動いている罠**(隠れていない。初めから見えている): 振り子(揺れる鉱石桶、骨の振り子、振り子の斧)は通路を横切って揺れ(ブォン)、刃が通路にある間に触れると当たる。噴き口(炉の火の噴き口、火を噴く穴)は3.4秒ごとに炎が噴き上がる(ゴッ)。間合いを測って抜ける。解除すると止まる。
- **予兆のない罠**(いままでどおり、セーヴか攻撃ロール。失敗すると働く)
  - 落とし穴(ガコン!): 一行ごと下の階のどこかの部屋へ落ち、全員が落下のダメージ。魔物は落ちていなくなる(経験点なし)。
  - 引き込み(水鏡の引き込み、ﾌｯ): 一行ごと同じ層の別の部屋へ。
  - **転移(迷い茸の輪、映し身の鏡、虚ろの口、転移の罠、ﾌｯ)**: 踏んだ**一人だけ**が別の部屋へ飛ばされ、仲間とはぐれる。はぐれた仲間は、道のりが届くまでその場で身を守る(Q で操作を替えて合流する)。
  - 落とし格子: 罠のある部屋の扉がすべて鍵のかかった格子になる。
  - 警報(叫び茸の輪 キィィィ!、鳴る床板 ギシッ): 近くの魔物が来る。召喚(鼠の巣穴の蓋、招魂の円、呼び寄せの声、召喚の罠 ズモモ…): そばに魔物の群れが湧く。
  - 毒(胞子溜まり、鉱毒の噴気): 8秒の毒。滑る・転ぶ(滑る苔の斜面、満ちる水門、沈む渡し石): 押し流されて転ぶ。転び(ぬめる苔溜まり、転びの罠 ステン!): 袋の燐晶の1/4が床に散らばる(拾い直せる)。
  - 眩惑(鏡の眩惑、濃い光の溜まり ピカッ): 6秒、見える範囲が2マスになる。恐怖(嘆きの共鳴、名を呼ぶ声): 4秒攻撃できない。回転(渦の床、回る床、回転板 グルン): 5秒、操作の前後左右が逆。
  - 錆(錆を噴く管、錆の罠 ジュワッ): その潜行の間、鎧の守りが1下がる(3まで)。冷気(祭壇の冷気): 8秒遅くなる。閉じる歯列: 3秒挟まれる(連打で抜ける)。逆さの重み: 1秒浮く。
  - 魔物がかかると: 眠り・網・転倒・眩惑・回転は気絶、恐怖は逃げる、錆は守りが割れる。
- **遺体の毒針**: 遺体を調べると、12%で毒針(チクッ)。【耐久力】セーヴ(難易度10＋層)に失敗すると毒。

## 迷宮の時間と休息

- **時刻は太陽と月で出る**(画面の上。1時間刻み)。潜り始めは朝7時。起きている間は実時間1秒で1分進む(ゲームの速さの設定もかかる)。
- **MP は迷宮では自然に戻らない**。HP と MP は休むと戻る(7時間でほぼ全快。魔力の泉は MP が 1.5 倍)。闘技場だけは、これまでどおり MP が戻る。
- **休む(C)**: 時間が早送りになり(1秒で50分)、6〜8時間で目を覚ます。もう一度 C、E、Esc、攻撃、移動で起きる(途中までしか戻らない)。敵に追われている間は休めない。
- **ワンダリング・モンスター**: 10分ごとに出現を振る(起きているとき 1/12、休んでいるとき 0.012)。起きていれば、見えない離れた所に出て、部屋から部屋へ歩き回る(気づけば追ってくる。見失うほど離れると、また歩き回る)。**休んでいるときに出ると、寝込みを襲われる**(近くに出て、1.5秒動けない)。同じ層に同時に3群まで。
- **吐く夜の群れ**は、順番待ちに並び、起きている魔物の数に空きがあるときに 1.5 秒に一組ずつ出る。この群れと、吐く夜の間に出るワンダリングは、仲間のいる所を目指して歩いてくる。
- **夜(20時〜6時)**: 起きたまま日が落ちると、吐息に呑まれて意識が遠のき、同じ層のどこかの部屋で朝を迎える(回復はしない)。夜にかかる休息は、夜明けまで続く。
- 数値は `scripts/balance.gd` の「迷宮の中の時間」、仕組みは `scripts/dungeon_time.gd`。

## 魔物の出し方(重くならないように)

広い層で魔物が多くても重くならないように、魔物は近づいたときに出し、遠くでは眠らせる(`scripts/spawner.gd`)。

- **層の遭遇は、最初は出さない**。仲間が 24 マスまで近づくか、その場所が見えたら出す(画面の外で出るので、湧く所は見えない)。数(`enc_total`)だけは先に数えてある。
- **遠い魔物は眠らせる**。仲間から 30 マスより遠い魔物は、動きも描画も止める。24 マスまで近づくと起こす。
- **起きている魔物の上限**(はじめ 100、40〜160)。FPS が 45 を切ると 10 ずつ下げ、57 以上なら 5 ずつ上げる。上限を超えたら、遠いものから眠らせる。14 マス以内の魔物と、見えている魔物は眠らせない。
- **ワンダリング・モンスターは眠らせない**。遠くでは軽い歩き方(絵も押し合いも無しで、位置だけを 0.25 秒ごとに道なりに進める)で、層を歩き回り続ける。近づくと、ふつうの歩き方に戻る。
- **押し合い**(`scripts/contact.gd`)は、升目で近い組だけを拾ってから計算する。群がって重なりが解けないときは、1コマに 240 組まで直して、残りは次のコマに回す。
- 重さの比べ: `tests/perf_probe.gd`(前のやり方と比べる)。確かめるのは `tests/spawner_test.gd`。

## パーティとクラス

キャラ作成では、名前、種族、クラス、能力値を決める。能力値は「ポイントバイ」(27点、8〜15。押すとクラスに合った配分になる)か、「ふる」(各3d6、3〜18。振った目のまま使う。何度でも振り直せる)で決める。操作するのは一人で、残りは自分で考えて戦う(Q で切り替え)。
始めは二人。3人目と4人目は、宿屋の「酒場で仲間を探す」から同じ画面で作る(いまは条件なし。条件は後で決める)。並び順(隊列)は、持ち物画面の「◀ 前へ」「後ろへ ▶」で、街でも迷宮でも入れ替えられる(宿屋でもできる)。
見た目はクラス × 種族 × 性別で描き分け、作成画面の左下で歩いて見せる(48通り。ドワーフの男は髭、エルフは尖った耳、ドワーフとハーフリングは背が低い)。

| クラス | 役目 | スキル(習得レベル) |
|---|---|---|
| 戦士 | HPと体当たりが高い。重い鎧 | 突進(1) 気合(2) 鉄壁(4) 薙ぎ払い(6) |
| 蛮族 | HPが最大。激昂で押し込む | 激昂(1) 猛進(2) 咆哮(4) 地鳴らし(6) |
| 盗賊 | 素早い。罠・隠し扉・解錠に強い | 投げナイフ(1) 速攻(2) 煙玉(3) 急所突き(5) |
| 魔術師 | MPが多い。遠くから削る | 魔弾(1) 火球(3) 氷結(5) 雷光(7) |
| 僧侶 | 回復と聖撃 | 治癒(1) 聖撃(2) 祝福(3) 大治癒(5) |
| 野伏 | 弓。罠の察知 | 速射(1) 三連射(2) 足止めの矢(4) 狙撃(6) |

キャラ作成では、**見た目(男性・女性)**も選ぶ。見た目と、クラスで、ドット絵のスプライトが決まる(歩きのアニメーションつき)。
種族は 人間(全能力+1)、エルフ(敏捷+2 知力+1、灯りの半径+1)、ドワーフ(耐久+2 筋力+1、レベルごとにHP+1)、ハーフリング(敏捷+2 魅力+1)。
スキルは、魔法屋の呪文書で増やせる(魔法の盾、眠りの雲、再生の光、閃光)。スキル1〜6への割り当ては、Tab のスキル欄で替えられる(初めはスキル1が武器の技)。
仲間の自動操作は、前衛は突っ込み、後衛は距離を取り、僧侶は傷ついた仲間を癒やし、技を状況に合わせて使う。

## 技能・セーヴ・特技(5e)

定義は `scripts/talents.gd`。習熟ボーナスは 5e と同じ(Lv1〜4 で +2、以後4レベルごとに +1)。

- **技能**: 5e の18技能。キャラ作成で、クラスの一覧から決まった数(戦士・蛮族・魔術師・僧侶は2、野伏は3、盗賊は4)と、生い立ちの2つを選ぶ。エルフは〈知覚〉に習熟。判定は「能力値の補正＋習熟」
- **生い立ち(生まれ表)**: キャラ作成の「ふる」で、ヴェルガ・ノクスのオリジナルの表(出身 d8、前職 d12、転機 d8、潜る理由 d8)をふる。表ごとに手で選び直せる。前職の技能2つが生い立ちの2つに入る(クラスや種族と重なれば別の技能で埋める。あとから好きな技能に替えてもよい)。ほかは読み物で、Tab のステータスに一文で出る。表は scripts/birth.gd
- **技能の効き目**: 判定の値を「点」として、迷宮での効き目に直す(0 未満は 0)。たとえば〈隠密〉は1点につき魔物に気づかれる距離が4%縮む。一覧は Tab の「技能・特技」で、技能を選ぶと出る

| 技能 | 効き目 | 技能 | 効き目 |
|---|---|---|---|
| 〈運動〉 | 押す力 | 〈動物使い〉 | 野獣・群れからの被ダメージ減 |
| 〈軽業〉 | 転がりの待ち時間が縮む | 〈看破〉 | 人型生物からの被ダメージ減 |
| 〈手先の早業〉 | 宝箱の燐晶が増える | 〈医術〉 | 回復量が増える |
| 〈隠密〉 | 気づかれる距離が縮む | 〈知覚〉 | 受動〈知覚〉(10＋点)で罠と隠し扉に気づく。探る(F) |
| 〈魔法学〉 | 呪文の威力 | 〈生存〉 | 罠のダメージ減 |
| 〈歴史〉 | 経験点が増える | 〈ペテン〉 | 店の買い取りが高くなる |
| 〈捜査〉 | 探る(F) | 〈威圧〉 | 傷つけた魔物が逃げ出しやすい |
| 〈自然〉 | 野獣・植物・粘体・群れへの与ダメージ | 〈芸能〉 | 街へ戻ると宿で稼ぐ |
| 〈宗教〉 | アンデッド・悪魔・天上の者への与ダメージ | 〈説得〉 | 店の値段が安くなる |

- **盗賊道具**: 解錠と罠の解除は「【敏捷】＋盗賊道具の習熟」。習熟しているのは盗賊だけ
- **セーヴ**: 罠のセーヴは、クラスの習熟(SRD 5.1 と同じ。戦士なら【筋力】【耐久力】)を使う
- **熟達**: 盗賊は Lv1 と Lv6 に2つずつ、習熟している技能か盗賊道具を選び、習熟ボーナスを2倍にする
- **能力値上昇と特技**: Lv4、8、12、16、19(戦士は 6、14 も、盗賊は 10 も)で、能力値を一つ +2、二つを +1 ずつ(20まで)、または特技を一つ選ぶ。Tab の「技能・特技」で、★ の行から選ぶ。選ぶまでは何も変わらない
- **特技**(12種。この企画で作ったもの): 頑健(HP)、鋭い目(知覚)、組みつき上手(押す力)、身軽(足と転がり)、渾身(体当たり↑、被ダメージ↑)、盾構え(溜めている間の軽減と反撃)、魔力の泉(MP)、呪文の冴え(呪文の威力)、射手(飛び道具の威力と射程)、癒し手(回復量)、幸運(判定の振り直し)、不屈(一度の潜入で一度、HP1で踏みとどまる)
- 闘技場でレベルを変えると、選んでいない分は、クラスに合わせて自動で埋まる
- 古いセーブは、能力値はそのまま、技能はおまかせで読み込む(盗賊の熟達は、未選択になる)

## 街

背景の絵は、画像素材を使わずコードで描いている(`scripts/town_art.gd`。大穴と七角形の内壁の夜景、各店の内装、寝息通り)。

街に戻ると、坑口前の広場に立つ。夜景の上に店の看板が立っていて、看板を選ぶ(マウスを重ねる、十字キーで動かす)と、下の帯に通りの様子が一行出る。看板を押すと店へ入り、店の主の一言と品物が出る。「◀ 広場へ戻る」か Esc(B)で広場へ出る。迷宮へは、坑口の青い看板から降りる。持ち物、操作の設定、闘技場、タイトルへは、下の帯の小さなボタンから。持ち帰った燐晶の査定は、広場に着いたとき、看板の上に報告として出る。

| 場所 | できること |
|---|---|
| 武器・防具(鍛冶組「炉火の槌」) | 武器、鎧、小盾、腕輪、長靴の売買。買ってそのまま装備できる。誰が装備できるか、変化はどうなるかが出る |
| 雑貨屋(「灯守の店」) | 治療薬、魔力水、燐晶の灯油、帰還の札、指輪など |
| 魔法屋(星録の書院・写本室) | 呪文書(買って覚える)、魔晶の杖、魔力の指輪 |
| 神殿(静寂派・癒院) | 倒れた仲間の蘇生(寄進 100×レベル銀貨)、加護(次に潜るとき、しばらく被ダメージ減) |
| 宿屋(「止まり木亭」) | 泊まって全快(30銀貨/人)、酒場の噂、酒場で仲間を加える(最大4人)、酒場で加えた仲間と別れる(装備は外して持ち物に残る。主人公と相棒は別れない)、並び順の入れ替え(先頭が隊列の先頭で、迷宮で最初に操作する)、セーブ |
| 花街(寝息通り) | 雰囲気だけ。歩く、灯籠を見上げる、占い師の屋台 |
| 冒険者ギルド(坑口館) | 遺品課: 認識票や遺品を引き取り、謝礼を出す(認識票と遺品の装備は、ここでしか引き取らない)。帰還積立: 次の潜行で全滅しても、装備は戻り、持ち物は半分で済む(掛け金は 20 + 10×仲間のレベルの合計)。掲示板: 依頼を受け(3件まで、日ごとに貼り替わる)、品を揃えて納品すると報酬。査定課: 前回の査定を読み返す |

### 座暦とセリフ

街の右上に、今夜の座暦の日付が出る(`scripts/za_calendar.gd`)。物語は座暦2352年 狩人の月(8月)1夜から始まり、潜るたびに一夜進む。1月は30夜で、12月(空座の月)のあとに座渡しの5夜がある。2352年は大閏の年で、空座の月が79夜まで続く。巡りの節(第一節〜第七節の夜)は、迷宮の夜の名と同じ。

広場に着いたときと戻ったとき、看板、宿の主人の挨拶、酒場の噂、寝息通り(歩く・見上げる・占い)の行は、月ごとに替わる(`data/town_lines.json`、`scripts/town_lines.gd`)。祭りなどの夜(新年、炉開き、誓剣の月の始まり、暦官の告示、灯祭、年の市、空座の七七夜の始まり、沈黙の夜、母の三夜、座昇り)は、その夜だけの行になる。

## 持ち物(Tab)

- アイテム: 治療薬などを、選んだ仲間に使う。呪文書もここで読める。灯油と帰還の札は、迷宮の中で効く。
- 装備: 武器、防具、装飾品を替える。替えたときの体当たり、防御、HP、MP の変化が出る。クラスで着られない物は × で示す。
- スキル: スキル1〜6への割り当て。
- 技能・特技: 技能の判定値と効き目を見る。★ の行から、能力値上昇・特技・熟達を選ぶ。
- ステータス: 能力値と派生値、習熟ボーナス、受動〈知覚〉、セーヴ、特技。

## 闘技場(戦闘バランスの調整用)

街の下の帯の「闘技場」から入る。広い一部屋で、魔物の群れと何度でも戦える。経験点も宝も出ない。パーティは本編の仲間の**複製**なので、レベルを変えても本編には影響しない。
右の盤(F2 で出し入れ)で、次のことができる。ボタンは、キーボードの操作を邪魔しない。

| 操作盤 | できること |
|---|---|
| 敵をポップ | **遭遇レベル**(1〜20)、難度(低・中・高)、舞台(魔物の種類)、予算の人数を選んで、「ポップ」。実際の迷宮と同じ生成の規則(SRD の経験点の予算)で、遭遇を出す。続けて何度でも出せる。「全消去」 |
| 連戦 | 倒したら、自動で次の波を出す。波ごとに遭遇レベル+1、波の間に全回復、を選べる |
| キャラクターのレベル | 一人ずつ、または「全員」を、レベル1〜20に替える(HPとMPは全快、そのレベルまでのスキルを覚え、選んでいない能力値上昇・特技は自動で埋まる) |
| 係数 | 敵の攻撃の強さと間隔、体当たり、押し合い、最大HP、防御の軽減率、罠。**スライダーで、その場で効く**。「値をコピー」で、`balance.gd` へ貼れる形でクリップボードへ。「初期値に戻す」 |
| 記録 | 波ごとの、かかった秒数、敵の数とXP、与ダメージ、被ダメージ、倒れた人数。仲間ごとの、与えた/受けたダメージ |

出口は、左下の階段(E)か、盤の「街へ戻る」。全滅すると、記録して全快する(連戦は止まる)。

## 数値(`scripts/balance.gd`)

| 項目 | 扱い |
|---|---|
| 魔物のダメージ式、脅威度、XP | SRD のまま |
| 魔物のHP | SRD の hp × 1.5(`ENEMY_HP_SCALE`) |
| 魔物の AC | 被ダメージの軽減率 (AC−10)×3% |
| 魔物の攻撃 | 1ラウンドのダメージ × 0.4 を、1.6秒で割った毎秒ダメージとして、体当たりで与える |
| 移動速度 | 1フィート/ラウンド = 4画素/秒(30フィートで秒速120。仲間は150)。魔物はさらに × 0.85(`ENEMY_SPEED_SCALE`) |
| 仲間の通常攻撃 | 一撃 = 火力 × 待ち時間 0.5秒 × 1.3(`ATTACK_SCALE`、`ATTACK_CD`)。溜めの一撃はその 1.6〜3.0倍(`CHARGE_MULT`) |
| 経験点 | 倒した魔物のXPを、生きている仲間で等分。レベルは SRD の表 |
| 遭遇の量 | 人数に比例(1〜4人の4通りを書き出してある) |
| 仲間のHP | クラスのヒットダイスと耐久で決め、×1.5 |
| 罠 | セーヴや攻撃ロールは、踏んだ仲間のもの(セーヴは能力値の補正＋クラスの習熟)。難易度とダメージは SRD の表のまま(ダメージ ×0.6、〈生存〉で減る) |
| 探る・解錠 | 判定は d20＋技能(探るは〈知覚〉か〈捜査〉、解錠と罠の解除は盗賊道具)。パーティでいちばん得意な人が振る |

## 分かっている限界

- 生成器は JavaScript のまま(JSON を読む方式)。夜は7夜で一巡する。無限に作るには、生成器を GDScript へ移す(展開メモ §3.3)
- 魔物の特徴は、動きで見て分かるものだけ(上の「魔物の特徴」)。生来の呪文(Innate Spellcasting)、ダメージの耐性・抵抗は未対応
- 「交渉の余地あり」の魔物と話す手段は無い(手を出すまで動かないだけ)
- 通路は幅1マス。第10層の先は無い
- 花街は雰囲気だけで、仕組みは無い
- 音と効果音は無い。固定の画面比(16:9)で作ってある
- 数値は初版。遊んで直す前提(特に、敵の毎秒ダメージと押し合いの強さ)

## マップチップ

床、通路、壁、扉、階段、宝箱、罠は、舞台ごとのドット絵(32×32、つなぎ目なし)を同梱している(`assets/tiles/`、`tools/make-tiles.py` が描く)。床と壁は変種を混ぜて敷く。置いた画像が優先される。作り方のプロンプトは `docs/tile-prompts.md`。

## 広い迷宮、光る燐晶、税のかからない自生物

- 層(第N層)は、1〜5階のグループ(第1〜2層は5階、第3〜6層は4階、第7層からは1階。全30階、深さ約200m)。1階の広さは、第1〜2層が 192×128、第3〜6層が 128×86、第7層以降が 96×64。全階の中央を 20m四方の縦穴(虚空。歩けないが見通せる)が貫き、第10層(第30階)の底は竜の巣(縦穴の内側が部屋。赤竜が眠っていて、着くと実績。下り階段は無い)。第5〜6層(水鏡)には水路 `~`(歩けないが見通せる)と浅瀬 `=`(歩けるが速さ半分。水に棲む魔物は平気)と橋、第7層以降の骨と水鏡には柱 `I`(通れず見通せない)。階段は縦穴を囲む7つの候補地を夜ごとに巡る(下の階の上り階段は、この階の下り階段の真下)。第1〜6層には昔の竪坑の穴が4つあり、落とし穴は真下の階へ落ちる。魔物は、巣の間隔(縄張り)を取って置く。理由と数字は `docs/dungeon-scale.md`、`docs/dungeon-ecology.md`、`docs/dungeon-model.md`。
- 宝箱は無い。燐晶は、床に落ちている**光る石**(純度 低・並・高・極・不明)。近づくと吸い寄せられて拾える。宝の部屋、壁ぎわの露頭、遺体、倒した魔物から手に入る。
- 拾うと、その物の絵が拾った仲間の頭の上へ跳ね上がり、右の地図の下に絵つきで知らせが出る(続けて同じ物を拾うと、数や重さをまとめる。`pickup_pop.gd`、`hud.gd`)。
- 施錠された扉の解錠は、成功すると錠前の弓が外れて金の光が散り、失敗すると錠前が揺れて赤く光る(`unlock_fx.gd`)。
- 擬音はこのゲームの看板で、効果音も曲も入れない(ken 10/16、曲は 10/17)。擬音は Dela Gothic One で一文字ずつ動く。動き方は8つ(pop 弾ける / slam 叩きつけて揺れる / bounce 一文字ずつ跳ねる / shake 震える / stretch 一文字ずつ伸びる / soft ふわっと / snap 横から滑り込む / wave 波打つ)で、擬音ごとに `Sfx.STYLE` で決める(`sfx.gd`、`cue_text.gd`)。
  地上へ戻るとき、純度ごとに査定され、**3割が燐晶税**。
- 茸や苔、魔物の素材、遺品は、**燐晶ではないので、税がかからない**。持ち物に入り、食べる・使う・売る。一覧は `docs/items-and-forage.md`。
- アイテムの絵は、16列のシート(`assets/items/items_sheet.png`、`tools/make-items.py`)。プロンプトは `docs/item-prompts.md`。
- 量の調整: `Balance.CRYSTAL_SCALE`(燐晶)、`Balance.FORAGE_CELLS`(自生物の密度)。
