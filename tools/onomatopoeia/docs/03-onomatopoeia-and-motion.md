# オノマトペと動きの対応(音象徴・動的音喩)

(2026-10-19 調べ。各項目の「取り込んだもの」は `cue_nodes.js` のノード名・例の名前)

### Fukusato, Morishima「Automatic depiction of onomatopoeia in animation considering physical phenomena」ACM SIGGRAPH MIG 2014
- 出典: https://dl.acm.org/doi/10.1145/2668064.2668096 (https://www.researchgate.net/publication/286808730)
- 内容: CG の衝突の物理量(質量・体積・加速度・粘性など 6 つ)から、100 語の衝突の擬音の中から合うものを選んで画面に置く。擬音は音素のベクトルで表す。500 人超の評価で「動きが生き生きする」。配置は視点依存のガウス関数で、重なりを避ける。
- 取り込んだもの: ノードではなく、ゲーム側の設計。「出来事の物理量 → 擬音」の段は sfx.gd の CUES の選び方(重い = 濁音、など。`design/2026-10-17-onomatopoeia.md`)に当たる。配置の「重なりを避ける」は未実装(続けて出る擬音は間引いている)。

### Koguchi, Yamada, Taura「The database of motion constructed by focusing on mimetic words」ICED 2013
- 出典: https://www.designsociety.org/download-publication/34584/
- 内容: 擬態語 52 語を 9 語(ひらひら、ぴょんぴょん など)に束ね、動物や植物の実写から取った 160 の基本動作と対応づけた。動きの「リズム」= 動きの量と角速度の変化。人の一致は弱い(最高 46%、κ=0.46)が有意。
- 取り込んだもの: `rhythm`(音節ごとに位相をずらした振動)。例 `ex_hira`。「一致が弱い」ので、ひらひらの割り当ては実験室で見て決める。

### 三浦佳世「オノマトペによる速度感」人工知能学会全国大会 2011
- 出典: https://www.ai-gakkai.or.jp/jsai2011/webprogram/2011/pdf/35.pdf
- 内容: 擬音語は速さを、擬態語は軌跡や様態を伝える。運動線と擬音が一致すれば言葉が優先される。
- 取り込んだもの: 指針。fly(ヒュッ)の残像は運動線の代わりで、言葉と向きを一致させる(`dir`)。

### 中佐古真実・松村耕平・野間春生「オノマトペのイメージを考慮した可視化による子どもたちの表現能力向上の試み」インタラクション 2016
- 出典: http://www.interaction-ipsj.org/proceedings/2016/data/pdf/2C44.pdf
- 内容: 62 語で、太さ(細・普通・太)と ひらがな / カタカナ の好みを一対比較で調べた。「てくてく」は細いひらがな、「ごそごそ」は普通の太さ。
- 取り込んだもの: 指針。ひらがな = 柔らかい音、は決まりに既にある。太さは Dela Gothic One 一本なので、細い擬音は半角カナ(ﾌｯ)で代える。

### 宮内彩璃・小林桂「日本漫画におけるオノマトペの体験型インスタレーションの検討」インタラクション 2024
- 出典: https://www.interaction-ipsj.org/proceedings/2024/data/pdf/1P-78.pdf
- 内容: 体験者の動きに合わせて手描きの擬音を出す。動きの大きさで字体や大きさを変える案は今後の課題。
- 取り込んだもの: 無し(方向が同じ、という確認)。

### 松下光範・今岡夏海「ディジタルコミック制作のための動的な音喩表現生成システム」人工知能学会全国大会 2011
- 出典: https://www.ai-gakkai.or.jp/jsai2011/webprogram/2011/pdf/232.pdf
- 内容: 『ドラゴンボール』『風と木の詩』から音喩を集めて 8 分類。動きのパラメータは 速度・角度・移動方向・振れ幅・フォントの大きさと色。例: 「シュバッ」= 左右に動きながら落下、「ドキドキ」= 出現と消失のくり返し、「ズゴゴゴゴ」= 振動しながら一方向へ進む。**振れ幅の値で音喩の文字そのものが ぷるぷる / ぶるぶる / がたがた に変わる**(動き → 文字、の向き)。
- 取り込んだもの: 指針。「ドキドキ」の点滅は `loop` + `step` で書ける。「振れ幅で文字が変わる」は、ゲームの CUES を「強さの段」で分ける考えと同じ(ドン → ドンッ → ドンッ゙!)。

### 寺島亜耶香・上間大生・松下光範「効果線の描画に着目した動的音喩の付与手法」人工知能学会全国大会 2012
- 出典: https://www.ai-gakkai.or.jp/jsai2012/webprogram/2012/pdf/36.pdf
- 内容: 漫画から音喩と効果線の組 156 件を収集。「ふらふら」には緩やかな波線が対応し、「ゴゴゴゴ」は共通する線が無い(対象外)。描く速さと音喩の速度感が対応(シュッ は速く、すー は遅く描かれる)。
- 取り込んだもの: 指針。fly の残像 = 速い線、stretch(ギィ…)= 遅い線。「ゴゴゴゴ に線が無い」は、ゴゴゴゴ が音ではなく雰囲気(`05-games-video-sns.md` の JoJo)だから。

### 陳萍「BCCWJ と擬音表記における語末に現れるオノマトペ標識について」若手研究者フォーラム要旨集 5, 2022
- 出典: https://ir.library.osaka-u.ac.jp/repo/ouka/all/87124/wkf05_023.pdf
- 内容: 語末の標識の意味(浜野の音象徴・角岡のアスペクト): **促音 ッ = 運動の収束・急な動作**、**撥音 ン = 余韻・跳ね返り・反動**、**り = ゆったり・完了**、**長音 ー = 持続**、反復 = くり返し。漫画の擬音では っ・ん・ー の割合が高く、「ーっ」「ーん」「んっ」の順で組み合わさる。
- 取り込んだもの: 指針(ゲームの擬音の作り方)。ッ で終わる擬音は slam / snap のように**止まって終わる**、ン で終わる擬音は余韻(揺れ戻し)を残す、ー は stretch、反復は bounce。`ex_telop` の「止まって抜ける」と、「ッ゙」を最上段にする案(`04-dakuten.md`)はこの表に沿う。

### 平田佐智子ほか「Twitter を用いたオノマトペ記述データの収集システム」人工知能学会全国大会 2011 / 秋田喜美ほか「オノマトペのインタラクション性に関する量的考察」同 2012
- 出典: https://www.ai-gakkai.or.jp/jsai2011/webprogram/2011/pdf/132.pdf 、https://www.ai-gakkai.or.jp/jsai2012/webprogram/2012/pdf/240.pdf
- 内容: 平田: Twitter で「○○ってどんな感じ?」と聞いて集める辞書(オノマトペハンター)。「洗濯」の擬音が ざぶざぶ から ゴウンゴウン(洗濯機)へ移っている。秋田: Twitter のリプライでは擬音語が相手を巻き込む語として少し多く出る(p<.10)。国会会議録では発話の後半に増える。
- 取り込んだもの: 指針。擬音の意味は時代で動くので、ゲームの CUES も「いま通じるか」を実験室の帳面で見る。

### 秋田・Pratha ほか、横井(ほかに読んだもの)
- Pratha, Avunjian, Cohn「Pow, punch, pika, and chu: The structure of sound effects in genres of American comics and Japanese manga」Multimodal Communication 2016: https://www.degruyterbrill.com/document/doi/10.1515/mc-2016-0017/pdf (抄録のみ。日本の少年誌と少女誌で片仮名 / 平仮名の使い分けが違い、英語ではフォントの装飾がその役を担う)
- 横井雅之「さまざまな音の擬音語表現について」大阪産業大学 人間環境論集 23: https://osu.repo.nii.ac.jp/record/2000134/files/23-29.pdf (音を 衝撃音・打音・摩擦音・空気音 に分け、摩擦音を 鳴き音(キーン、ギー)と こすれ音(ガタガタ、キュッキュッ)に分ける。ゲームの擬音を動き方に割り当てるときの分類に使える)
