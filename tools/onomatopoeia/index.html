擬音の実験室

ゲーム(cue_text.gd / sfx.gd)の描き方を JS に写した道具。舞台を押すと発生点を置き、再生で動きを見る。帳面はこのページに残り、Claude も読める。

擬音の一覧(sfx.gd から)

押すと「いまの擬音」になる。もう一度押すか、舞台を押すと発生点に置く。

いまの擬音(自由入力もここ)

ノード(実験): 動きをノードのグラフで書く

ノードの種類

props の x y sx sy rot alpha spread が性質。入力は 数 / ノード id / 入れ子。t px dx dy i n seed big g は id だけで引ける。copies は残像(fly)。

実験(ゲームにはまだ無い)

奇数番目の組は、横の動きと傾きを反転し、出てすぐ横に振れて戻る。ひらひらひら、ゴロゴロゴロ… で見比べる。

0.00 s

舞台を押すと、いまの擬音の発生点を置く(ゲームと同じ ×2 の拡大)。発生点ごとに遅れ(秒)を変えられる。時間の棒をなぞると止めて見られる。

書き出し(リール向けの試作)

透過が要るなら APNG か PNG 連番(どちらも背景「透過」で)。動画の編集ソフトに入れるなら PNG 連番が確実。WebM は背景を緑にしてクロマキーで抜く。拡大は「ゲームの ×2」と同じ尺度で、1080 幅に 14px の字を ×6 で 84px。Instagram のリールは 1080×1920・最大 30fps 推奨(出す側で変換される)。
