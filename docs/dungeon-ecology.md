# 魔物の生存圏と、都市・迷宮の広さ

## 1. 問い

> 魔物にも生存圏がある。もっと広くしないと、魔物同士が争うのでは。都市の大きさと、その周りの地下に広がる迷宮の広さを考えて。層はグループなので、複数階にまたがってもよいのでは。

## 2. 結論

- **賛成。** 層は、階のグループにする。迷宮は、都市の下にも、荒野の下にも広がる、とてつもなく広い空間。ゲームの地図は、その中の「区画」。
- ただし、**地図を広げるだけでは足りない。** 魔物の数を変えないと、広くしても、詰め込んだままになる。縄張りの広さを決めて、巣の間隔と密度を、層ごとに設けた。
- 結果、魔物の混み具合(縄張りの重なり)は、**6〜12倍 → 約2倍**になった。階は、18階(10の層が、1〜3階ずつ)。

## 3. 都市と迷宮の広がり(見積もり。都市資料に数字がないため【案】)

都市資料にあるのは、人口 約3万、二重城壁(内壁は大穴を囲む正七角形)、下流の畑 約1,000ha、海嘯の規模(階級五で5万体超)、最深到達の第九層。大きさの数字はないので、次のように見積もった。

| 項目 | 見積もり | 根拠 |
|---|---|---|
| 都市の広さ | 約3km²(外壁の半径 約1km) | 約3万人を、1haあたり約100人(城壁都市)で収める。冠環区の丘、縁環区、壁下区を含む |
| 大穴 | 半径 約300m | 内壁(正七角形)の内側。壁下区は、その斜面と外周 |
| 迷宮の水平の広がり | 第1〜2層: 半径約3km(約28km²)、第3〜4層: 約2.5km(約20km²)、第5〜6層: 約2km(約13km²)、第7〜9層: 約1.2km(約4.5km²)、第10層以降: 約0.6km(約1.1km²) | 400年掘り進めた。浅層ほど広く、都市の下にも荒野の下にも伸びる。深いほど細い(円錐) |
| 魔物の総数 | 約6万体(第1〜2層 3万、第3〜4層 1.8万、第5〜6層 0.9万、第7〜9層 0.3万、第10層以降 約0.05万) | 大海嘯(階級五)は、5万体を超えて溢れた。迷宮には、それ以上いたはず |
| 魔物の密度(平均) | 第1〜2層 約11/ha、第3〜4層 約9/ha、第5〜6層 約7/ha、第7層以降 約5〜7/ha | 総数 ÷ 広がり |

- 迷宮の各層(第N層)は、この広がりを持つ。層は、階が積み重なったもの。
- **ゲームの地図は、その1%ほど**(第1層で、3階ぶん 約17haが、層の約1,400haのうち)。ギルドが案内する、巣の集まる一帯。

## 4. 縄張りの考え方

- **巣は、部屋。** 魔物は、燐の気を吸って生きるので、餌をほとんど要らない。だが、巣のまわりに縄張りを持つ。
- **巣どうしの間隔**を、大きい魔物ほど広く取る(生成器の `DEN_SEP`、マス)。近すぎる部屋には、巣を置かない(代わりに、見張りのない蓄えがあることがある)。

| 大きさ | 巣の間隔 | 縄張り(1体、歩ける床のm²) |
|---|---|---|
| 超小型(T) | 9マス(約14m) | 150 |
| 小型(S) | 10マス | 250 |
| 中型(M) | 14マス(約21m) | 600 |
| 大型(L) | 20マス(約30m) | 1,500 |
| 超大型(H) | 28マス | 4,000 |
| 巨大(G) | 36マス(約55m) | 10,000 |

群れは、数が多いほど間隔が広がる(最大 +60%)。縄張りは、群れの数の0.6乗で、分け合う。

- **混み具合** = 巣の縄張りの合計 ÷ 歩ける床の広さ。1なら、ちょうど。**2〜3まで**は、共有の狩場として許す(重なって、ときどき衝突する)。**5以上**は、常に争う。
- 密度の係数 `density` は、巣のある部屋の割合にかける(標準 1)。深い層ほど小さい(強い魔物ほど、縄張りが広い)。

## 6. 層は、階のグループ

| 層 | 呼称 | 階 | 1階の広さ |
|---|---|---|---|
| 第1層 | 腐葉の回廊 | 3 | 超広大(192×128) |
| 第2層 | 腐葉の回廊 | 3 | 超広大 |
| 第3層 | 錆鉄の坑道 | 2 | 広大(128×86) |
| 第4層 | 錆鉄の坑道 | 2 | 広大 |
| 第5層 | 鏡の水廊 | 2 | 広大 |
| 第6層 | 鏡の水廊 | 2 | 広大 |
| 第7〜9層 | 骨の大聖堂 | 各1 | 特大(96×64) |
| 第10層 | 第10層以降(仮) | 1 | 特大 |

- 階段は、通し番号の階を、1つずつ降りる(18階)。HUD は「第1層 2/3階」と表示する。
- 層が決めるもの: 舞台(絵、罠、魔物の候補)、魔物の強さ、燐晶の純度、拾える自生物、装備の質。**同じ層の階は、同じ強さ**(階ごとに少し上げる案は、未確定)。
- 同じ層の2〜3階めは、別の地図(種を変える)。

## 7. 実装

- `Core.generate` に、`ecology`(巣の間隔)と `density`(巣のある部屋の割合、通路をうろつく魔物の数)を足した。標準は、どちらも従来どおり。
- `tools/export-floors.mjs` の `LAYERS` に、層ごとの階の数、広さ、密度。ファイルは gzip(504ファイル 約5MB)。Godot は `FloorMap.read_json` で読む。
- `Balance.MAX_FLOOR` は 18(階)。`FloorInstance.floor_no` は階の通し番号、`layer_no` は層。拾えるもの、装備の質は、層で決まる。
- `node tools/analyze-ecology.mjs` で、この表を作り直せる。

## 8. 【未確定】

- 都市と迷宮の広さの数字(§3)を、都市資料に書き足すか。大穴の大きさ、外壁の半径は、案。
- 魔物同士が争う様子を、ゲームで見せるか(巣の間にいる魔物が、別の群れと争っている)。いまは、巣の間隔を取るだけ。
- 魔物の移動(夜ごとに巣が移る)、海嘯のときの動き。
- 密度の目標(総面積あたり 約15/ha)が、遊んで合うか。
- 階ごとに強さを上げるか(同じ層でも、深い階ほど強い)。
