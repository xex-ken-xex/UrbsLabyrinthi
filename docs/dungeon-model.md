# 燐の循環 — 数百年枯れない迷宮の数理モデル

## 1. 問い

> 400年掘られて、年に100t以上の燐晶を出しながら、なぜ迷宮は枯れないのか。層ごとの魔物・燐晶・遺体の数は、都市の数字(冒険者3,000人、燐晶の取引600万銀貨、死者1,100人)と合うのか。生成器に入れる数を、一つの模型から出したい。

結論: **迷宮は鉱山ではなく、燐の循環の一部。** 底で眠るものの息(燐の気)が魔物の体になり、魔物が死ぬと燐晶になる。冒険者は燐晶を掘っているのではなく、魔物を殺して燐晶を育てている。採取の合計(年163t)は魔物の生産(年177t)を超えないので、迷宮全体は枯れない。ただし浅層は、人が来る前に溜まっていた鉱脈を400年掘りつづけて、いま尽きかけている(第1層はあと約24年)。

## 2. 循環の形

```
眠るものの息(燐の気、年 約220t)
  ↓ 縦穴を上がりながら、層ごとに魔物の体になる(深いほど濃い)
魔物(全層で約6万体。深いほど大きく、体の燐が多い)
  ↓ 死ぬ(自然死 年0.5/体 + 冒険者が殺す)
燐晶(死骸の燐の8割が結晶になる)
  ├ 拾われる(冒険者の採取。年 約163t)
  └ 拾われず埋まる → 鉱脈(壁の中の燐晶。年に 1/1000 ずつ下の層へ流れる)
                      ↓
                    底の蓄え(縦穴の底。約9,400t = 竜の寝床、高さ約18m)
```

- **深いほど純度が高い**: 燐の気の濃さは底から上へ e 倍ずつ薄くなる(λ = 100m)。値段 = 200 × e^(−(200 − z)/100) 銀貨/kg。これで純度の表(低30・並50・高80・極140・不明200)が ±20% で出る。
- **海嘯**: 息の一時のあふれ。大海嘯の5万体は、息の約1か月半ぶん(25t)。
- **燐は下へ流れる**: 鉱脈は少しずつ下の層へ。だから深い層の鉱脈は上の層より太く、底にすべてが溜まる。評議会が深層の探索を抑える理由(案1「市場価格の崩壊を恐れる」)に数がつく。底の蓄えは都市の約150年ぶんの取引に相当する。

## 3. 式

層 ℓ ごとに(年あたり):

| 量 | 式 |
|---|---|
| 殺される数 K_ℓ | 潜行の数 × 1回に倒す数 |
| 生まれる数 B_ℓ | 0.5 × M_ℓ + K_ℓ(定常なので、生まれる数 = 死ぬ数) |
| 息の取り分 | B_ℓ × q_ℓ(q は魔物1体の燐、kg) |
| 燐晶の生産 R_ℓ | B_ℓ × q_ℓ × 0.8 |
| 採取 H_ℓ | 潜行の数 × 1回の持ち帰り(kg) |
| 圧力 | H_ℓ / R_ℓ。1を超えると鉱脈を削っている |
| 拾える燐晶(床と壁ぎわ) L_ℓ | R_ℓ × τ、τ = 1 / (1 + 圧力) 年 |
| 鉱脈 V_ℓ の変化 | +(R_ℓ − min(H_ℓ, R_ℓ)) −(H_ℓ − R_ℓ)⁺ − ρ V_ℓ + ρ V_{ℓ−1}、ρ = 1/1000 |
| 底の蓄え | Σ ρ V_10 |
| 値段 p(z) | 200 × e^(−(200 − z)/100) |
| 残る遺体 | 死者 × 0.7(持ち帰られない) × 15年 |

鉱脈は、大穴が開く2,000年前から溜まっていたとして(人が来る前は自然死だけ)、400年の人の推移(採掘者の時代 → 大採掘 → 大海嘯 → 深層の抑制 → いま)で年ごとに積分する。

## 6. 枯れない理由(まとめ)

1. **燐の源は息。** 魔物は息から生まれ、死んで燐晶になる。冒険者が殺すほど燐晶は増える(第1〜4層の生産の9割は、冒険者が殺した魔物から)。だから採取が続いても、迷宮全体の燐晶は減らない。
2. **浅層が尽きかけているのは鉱脈。** 人が来る前に2,000年溜まった鉱脈を、採掘者の時代から掘りつづけた。第1層はあと約24年、第2層は約180年。鉱脈が尽きても、魔物を殺して得る燐晶(年23t)は残るので、灰の稼ぎが4割減るだけで、迷宮は枯れない。査定が少しずつ上がっているのは、この減り方の表れ。
3. **深い層は手つかず。** 第3層より下は採取が生産を超えず、鉱脈は400年前より太い。深層の探索権が政治問題になるのは、ここに都市の150年ぶんの燐晶があるから。
4. **海嘯は息のあふれ。** 5万体は息の1か月半ぶん。掘りすぎ(鉱脈を削って息の通り道を広げた)で溢れた、という歴史と合う。

## 7. ゲームへの写し方

- 生成器(`docs/urbs-labyrinthi.html` の `Core.WIRE`)は、`node tools/dungeon-model.mjs --json` の層ごとの目安(1階の魔物の数 `mon_floor`、燐晶 `kg_floor`、遺体 `bodies_floor`、1体が落とす燐晶 `drop_kg`、値段)を持つ。`tools/check-floors.mjs` が、書き出した階がこの目安に収まるかを確かめる。
- 魔物の数は、層の平均の2倍(ギルドが案内する一帯は巣が集まっている。docs/dungeon-ecology.md §5)。
- 燐晶は、露頭と宝の部屋に `kg_floor`(拾える燐晶 + 鉱脈の 0.5% が露頭として顔を出す)。深い層ほど多い(手つかずの鉱脈)。Godot の `Balance.CRYSTAL_SCALE`(いま 0.3)は、そのまま。Godot は、階に置く燐晶(宝の山と露頭)を `kg_floor` × `CRYSTAL_SCALE` に合わせる(`scripts/ground_items.gd` の `kg_factor`。`tests/flow_test.gd` が確かめる)。`tools/check-floors.mjs` の「生成器の宝」の列は、倍率をかける前の量。
- 区画(ゲームの地図、層の1〜2%)で1夜に育つ燐晶は 1kg ほど。プレイヤーの一行は平均の冒険者の何十倍も稼ぐ。これは「層の残り(魔物1.5万体、鉱脈)から区画へ流れ込む」と読む。同じ区画を毎夜掃除しつづければ層の魔物が減る、という手ざわりは、あとで入れられる(未実装)。
- 遺体は層の死者から(第1〜2層の1階に約20体、第3〜4層に約2体、それより下はほぼ0。第7層以降は120年前の遠征隊だけ)。

## 8. 夜の決まり

- 吐く夜は、夜の番号 mod 7 が 2 と 4(息継ぎ 3,1,4,5,6,5,7 の偶数)。
- 一画の地形は、吐く夜に必ず、静かな夜に4割の確率で組み替わる。期待 1.7夜でかわる(「地図は数日で無効」)。
- 階段の候補地は、夜ごとに息継ぎの数だけ進み、49夜で7か所を全部巡って元に戻る(GM §12.4 の四十九夜表と同じ式)。

## 9. 【未確定】つまみ

- 1回の潜行の持ち帰りと倒す数は、都市の数字に合わせて置いた値。遊んで直すなら、ここではなく `Balance.CRYSTAL_SCALE` と魔物の落とす量で。
- ρ(鉱脈が下へ流れる速さ)と、人が来る前の年数(2,000年)は、第1層が「尽きかけ」になるように置いた。
- 深い層の露頭(鉱脈の 0.5%)は、深層を豊かにしすぎないための値。
