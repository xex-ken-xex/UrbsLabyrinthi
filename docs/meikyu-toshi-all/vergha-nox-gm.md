### 0.1 設計メモ（矛盾を避けるための決め事）

- **「七」の扱い**: 七（七息、七角形、七芒星、七七夜、七つの水鏡の間）は、シナリオ「七七夜の星」の中核と、座暦（§5.6）に使う。制度や組織は、五長老会、十二座など別の数にして、七が埋もれないようにしている
- **暦の数字**: 座暦は 12（座）、7（節）、30（月）、365（年）、49（七七夜）、196（大閏）、2352（座暦の大巡り）で組み立てる。根拠は §5.6
- **年代の言い換え**: PL資料の「約400年前」「約200年前」「約100年前」は、座暦では392年前、196年前、98年前。どちらで答えてもよい（§2、§5.6）
- **動く壁と階段**: 通路や小部屋は夜ごとに不規則に変わる。ただし、層をつなぐ階段の出現位置だけは規則に従う。地図が数日で無効になるのは通路の話
- **呼吸の二層構造**: 長期の大きな周期（数か月〜数年）と、夜ごとの小さな息（七節の息継ぎ）がある。息継ぎが偶数の節の夜が「吐く夜」で、魔物が活発になる
- **評議会の票数**: 燐晶卿は3票で、過半数（5票）まであと2票。「あと一票」と言わない
- **静寂の母**: 十二座の一柱で、大陸では普通に信仰される女神。「穴を起こすな」の教義だけが、ヴェルガ・ノクスの静寂派独自のもの
- **海嘯（かいしょう）**: 大穴から魔物が波のように溢れる災いの呼称。「反乱」と紛らわしいため、「氾濫」は使わない。階級は、さざ波、うねり、小海嘯、海嘯、大海嘯の五つ（§15）
- **経済と軍事の数字**: §14、§15 の数字は設計値。前提は §14.1 に書いた。変えるときは、前提から直す
- **水と畑**: 西に濯ぎ川、川沿いに川畑がある。「荒野は雨が少なく、川の水を引ける畑のほかでは麦が育たない」が前提。食料の大半は輸入（§14）

## 1. 迷宮の真実

### 1.1 迷宮の真の名

**ウル・アウリス**（古語。「聴くものの底」）

- PL資料の「真の名は不明」に対応する。古い文書に断片が残るとされるが、完全な形を知る者はいない
- 迷宮の各呼称の関係
  - 螺旋の胃袋: 人間が最初に付けた、外から見た印象
  - 眠りの床: 教会が付けた、封じる側の名
  - 玉座の階: 目覚めの徒が付けた、迎える側の名
  - ヴェルガ大迷宮: 管理する側の名
  - ウル・アウリス: 迷宮自身、もしくは迷宮の底にいるものの名
- 【未確定】名の意味の解釈は、真相A/B/Cで変わる（§1.2）
- 【未確定】**名を呼ぶこと**: 古謡の削られた三息（§5.4）に「名を呼ばれ」とある。真の名を正しく呼ぶと、迷宮が応える。教会が削った本当の理由は、これかもしれない

### 1.2 真相の選択肢（GMが選ぶ）

「空座」「底の王」「静寂の母」の関係が、案によって変わる。

| 案 | 内容 |
|---|---|
| A. 深淵の呼び声 | 空座の主は実在し、底で目覚めを待っている。目覚めの徒の教義が正しい。「底の王」は深淵そのもの。星が閉じると、第十層への直通路が開く。ウル・アウリスは王の宮殿の名。招かれた者は、王に選ばれた者として扱われる |

## 5. 宗教の裏

### 5.1 空座

- 真相A/B/Cのどれを採っても、空座の神話は迷宮と関係している
- 大陸の他の神殿は、空座について「去った」「眠った」「まだ来ていない」と教える。どれも、ヴェルガ・ノクスの教会の教えとは別
- ヴェルガの教会は、「空座の神は眠っており、静寂の母が子守唄で眠らせ続けている」と、内輪では教えている。公の教えにはしていない（他の地域の静寂派との摩擦を避けるため）

### 5.2 静寂派（聖印司）の内情

- 教会は、「穴を起こすな」の教義が地方教義にすぎないと、大陸の静寂派から見られていることを知っている。そのため、静印の輸出と寄進で影響力を維持している
- 静印を授けた店ほど、教会に監視されている（§9）
- 聖印司の異端審問官は、禁書の写本を持つ者を追っている。目覚めの徒の取り締まりは、その延長

### 5.3 目覚めの徒

- 教義の出どころは、禁書の古謡の読み解き
- 信者は下層と色街の従業員に多い。穴蔵屋の奥の部屋が集会所になっている店がある
- 七七夜に向けて信者が急増している。星の完成日を以前から知っていた可能性がある（【未確定】）
- 初代教祖は元・静寂派の写本師（【未確定】）

### 5.4 子守唄「静寂の七息」

- 七節の子守唄。息継ぎ（句読点「、」）の数が、迷宮の階段の移動量に対応する
- 迷宮が従っているのは古謡版。教会版は、第四節から三息を削っている

**教会写本版（公式）**

> 一、眠れ、眠れ、母の腕に、星は遠く。
> 二、灯を消し、夜は静かに。
> 三、水は凪ぎ、風は止み、影は退き、鏡は閉じ、深き者よ眠れ。
> 四、底の王よ、夢を見よ、目覚めを知らず。
> 五、声を殺し、足音を消し、名を捨て、火を捨て、帰る道を忘れ、光を忘れ、眠れ。
> 六、母は歌い、母は祈り、母は待つ、朝は来ず、夜は終わらず、おやすみ。
> 七、七つの息で、七つの夜を、七つの鏡に、七つの灯を、七つの扉を、七つの眠りを、閉ざして、静寂。

**異なる節だけを抜き出した他の二版**

> 【坑夫の労働歌】六、母よ見ていて、朝まで灯を。
> 【古謡（禁書）】四、底の王よ、夢を見よ、夢のなかで、我らを数え、名を呼ばれ、目覚めよ。

**息継ぎ数**

|---|---|---|---|---|---|---|---|---|---|

### 5.5 印

- 静印（七角形）は、完全な囲い＝封印の象徴
- 七芒星（目覚めの徒）は、開かれた門の象徴
- ズレ3の軌跡は七芒星{7/3}になる。教会の七角形の封印は、実際には星に書き換えられつつある

### 5.6 座暦（暦の数学とその裏）

PL資料の座暦（§5.6）の背後にある数学と、物語との接続。

#### 数学モデル

夜を整数 N で表す。

| 量 | 式・値 |
|---|---|
| 節 | s = N mod 7（第(s+1)節の夜） |
| 七七夜の位置 | p = N mod 49。p が7の倍数の夜が朔夜（星の頂点） |
| 月 | 1〜11月は30夜、12月（空座の月）は30夜（大閏の年は79夜）、続いて座渡し5夜 |
| 年の長さ | 365夜（大閏の年は414夜） |
| 大閏の年 | 座暦が196の倍数の年 |
| 平均年長 | (196×365 + 49) ÷ 196 = 365.25夜 |

**位相のずれ**
- 365 = 52×7 + 1 = 7×49 + 22。年が替わるたびに、節の位相は1、七七夜の位相は22（= 3巡り＋1夜）進む
- 22 と 49 は互いに素なので、22k ≡ 0 (mod 49) となるのは k が49の倍数のときだけ。**49年で暦の位相が完全に元へ戻る**（七七年）
- 大閏の49夜は 49 ≡ 0 (mod 7) かつ (mod 49) なので、**節と七七夜の位相を乱さない**。暦を太陽に合わせる補正が、周期の構造を壊さない
- 49年（大閏なし）= 17885夜 = 49×365。大閏を含む49年 = 17934夜 = 49×366。196年 = 71589夜 = 49×1461
- 十二座が大閏を一巡する 12×196 = 2352年 = 48×49 を「座暦の大巡り」と呼ぶ

**大閏の年の構造**

| 区間 | 夜数 | 備考 |
|---|---|---|
| 1〜11月 | 330 | |
| 12月（空座の月） | 79 | 30夜のあと、31夜目から79夜目までが「空座の七七夜」（49夜） |
| 座渡し | 5 | 第一夜（年内410夜目）が座降ろし＝沈黙の夜 |

## 12. シナリオ「七七夜の星」

### 12.1 概要

夜ごとに変わる迷宮の構造を、法則から予測できると主張する地図師が現れる。その地図は的中し、パーティから引っ張りだこになる。しかし法則を解くほど、迷宮が自らの意思で道を作り替えていることが見えてくる。やがて地図師は、道筋に隠された「招待」を読み取ってしまう。

「子守唄の息継ぎ」と「mod 7 の足し算」の二つで、階段の位置を読み解くパズル。解くと、教会が信じる七角形（封印）が七芒星（門）に変わる。

**時間枠（座暦との対応）**
- 今年は座暦2352年、第十二の大閏（空座の番）。シナリオの49夜は、空座の月の延長部分（31〜79夜目）そのもの
- 第0夜は、空座の月の31夜目。「月が30夜で終わらない」ことが、街の人にも分かる合図になる
- 第49夜は、座降ろしの夜（沈黙の夜）。星が閉じ、空白が開く
- 階段の規則は、通常の年も働いている。刻みが読めるようになるのは、空座の七七夜に入ってから（【未確定】）。第0夜より前のエルシェの的中は、それまでの観測の積み重ね
- 暦の詳細は §5.6

### 12.2 エルシェ・ハルト（通称「数え屋」）

- **立場**: 地図師。元・聖印司付きの写本師。下層在住
- **経緯**: 禁書の古謡を複写するうちに、教会版が削られていると気づき、破門寸前で下層へ逃れた
- **癖**: 文章を読むと、句読点を数えてしまう
- **現状**: 第五層の階段位置を的中させ、ギルドとパーティから引っ張りだこ
- **世間の評判**: 優秀な地図師。法則の中身は誰にも話していない
- **内心**: 法則が当たるほど怖くなっている。規則が自然現象ではなく、読み手に向けて書かれた文章に見えるため。放置すれば、一人で「招待」を読み切ってしまう

### 12.3 舞台：第五層「七つの水鏡の間」

- 円形の部屋が環状に七つ並ぶ。時計回りに0〜6と番号を振る
- 毎夜、そのうち一つの部屋にだけ、第六層への下り階段が現れる
- 各部屋の水鏡の底に、一文字ずつ刻みがある。階段の光が差した夜にだけ読める
- 地図の中央には、通路のつながらない空白がある
- 刻み（部屋0〜6）: 底・待・汝・の・つ・を・王

### 12.4 数学モデル

- 夜 n の階段位置を S(n)（0〜6）とする。夜は第0夜から数える
- 夜 n の翌夜への移動量は、第(k+1)節の息継ぎ数 b。ただし k = n mod 7
- S(n+1) ≡ S(n) + b（mod 7）。7夜で一巡り
- 一巡りの移動量の合計 mod 7 を「ズレ D」と呼ぶ。一巡り後、階段は D 部屋ずれる
- D と 7 が互いに素なら、7巡り（49夜）ですべての部屋を一度ずつ回って元に戻る
- 各巡りの第0夜（朔夜）の位置を順に結ぶと、D=1 なら七角形、D=3 なら七芒星{7/3}。D=4（=-3）なら逆回りの七芒星（鏡像）
- 古謡版は D=3。朔夜は 0→3→6→2→5→1→4（→0）
- 第49夜に、中央の空白が「八つ目の間」として開く

| 数学 | 宗教 |
|---|---|
| 移動量 | 第k+1節の息継ぎ数（7は0に畳む） |
| ズレ D=0 | 教会版。毎巡り元に戻り、封印は閉じたまま |
| ズレ D=3 | 古謡版。階段が巡りごとに3部屋ずれる |
| 朔夜の軌跡 | 七角形か七芒星か |
| 49夜で閉じる | 七七夜で門が開く |

### 12.6 パズルと答え

謎は四段階。後段ほど前段の答えを使う。

**第一段階：観測帳から規則を読む**
- 資料: エルシェの観測帳（第0〜13夜）= 0, 3, 4, 1, 6, 5, 3, 3, 6, 0, 4, 2, 1, 6
- 答え
  - 移動量は 3, 1, 4, 5, 6, 5, 0 の七夜周期
  - 第20夜は2号室、第33夜は3号室
  - 一巡りの合計が24、24 mod 7 = 3 だけ毎巡りずれる

**第二段階：三つの子守唄から正しい版を選ぶ**
- 観測値と全節が一致するのは古謡版だけ（§5.4の表）
- 坑夫版もズレは3だが、第六節で食い違うため囮。ズレの量だけで判断すると間違える
- 早期に配る手がかり: ギルドの記録では、魔物が活発になる「吐く夜」は第三節と第五節の夜だけ。教会暦が警告する第四節の夜は静か。偶数節が三つある教会版では説明がつかない

**第三段階：四十九夜表から星を描く**
- 朔夜の部屋を順に結ぶと、頂点を二つ飛ばしで結ぶ七芒星{7/3}になる
- ズレが4でも同じ星が逆回りに描かれる。鏡の水廊では「鏡像」にあたる
- 教会が信じる七角形の封印は、実際には星に書き換えられつつある

**第四段階：招待状を読む**
- 部屋の番号順（教会式）に読むと「底待汝のつを王」で、意味をなさない模様に見える
- 朔夜の階段が灯す順（星の順）に読むと「底の王、汝を待つ」
- 朔夜と刻みの対応: 第0夜=底、第7夜=の、第14夜=王、第21夜=汝、第28夜=を、第35夜=待、第42夜=つ
- 招待状は七週かけて一文字ずつ書かれる。最後の「つ」が現れる第42夜の7夜後、第49夜に、中央の空白が「八つ目の間」として開く

### 12.7 「迷宮の意志」の見せ方

法則が当たるだけでは、意志は感じられない。エルシェの恐怖を段階的に育てるために、三つを使う。

1. **削られた息**: 迷宮は、教会が削った三息を正確に守っている。人間が忘れた歌を、迷宮だけが覚えている
2. **お世辞の階段**: エルシェが検証のためにわざと偽の地図を売った夜、本物の階段とは別に、偽の地図の部屋にも階段が現れた。迷宮は読み手に合わせて、誘いに来ている
3. **七七夜の締切**: 第49夜は、今年の沈黙の夜（大海嘯の日）と重なる。全市民が音を立てない夜に、人間の歌声が一切ない状態で星が完成する

### 12.10 ヒントと調整

**段階制のヒント**
1. 「差を取れ」: 階段位置そのものでなく、毎夜の差に注目させる
2. 「写本師は数える」: 句読点の数をエルシェに数えさせる

### 12.11 歌い直し（任意ルール）

水鏡の間で日没に節を歌うと、その夜の移動量を息継ぎの数に置き換えられる。迷宮の側の歌（深層の合唱）と対抗判定で争い、勝てばズレをずらして星を崩せる。ただし、沈黙の夜は人間の声が一切ないため、判定は不利になる。

| 権力の分散 | 封鎖令という大権を守護官が持つため、内乱を恐れ、権限の分散が進んでいる |

- 共同防衛の義務は、指揮に従う義務ではない。私兵と護印団が先に動いて、配置が食い違う（火種21）
- 【未確定】統帥の二席の人物と立場、共同防衛の発動条件、指揮の詳細は、別途検討する
- 【未確定】割れ方の例: 内壁を死守するか、外壁まで退くか。壁下区の住民を内壁の内側へ入れるか（火種20）。封鎖令を兆候で出すか、確証まで待つか（火種18）

**海嘯のときの役割分担**

| 担い手 | 役割 |
|---|---|
| 黒鉄 | 巨大な個体の足止め。個人で動く |
| 銀 | 小隊の指揮。冒険者と守備兵の連絡役 |
| 青銅 | 防衛線の突破を阻む遊撃 |
| 灰 | 補給、避難の誘導、負傷者の搬送 |
| 守備軍 | 城壁、弩、門の固定防衛 |
| 私兵 | 冠環区と燐晶卿の資産の防衛 |
| 護印団 | 静印塔の守り、静印の儀式 |
| 衛生隊 | 負傷者の搬送、疫病の対処 |

**内壁と静印塔**
- 内壁は、大穴を囲む正七角形。静印と同じ形で、七つの角に静印塔がある。護印団が詰める
- 七芒星は、七角形の頂点を一つ飛ばしで結んだ形。静印（閉じる囲い）と七芒星（開く門）が、同じ形の裏表になる。星の謎や、七つの水鏡の間の配置と響き合う【未確定】
- 壁下区は、内壁の「下」、大穴の側にある。海嘯のとき、最初に呑まれる

**冒険者の統制**（反乱への備え。【未確定】案）
- 入口の統制: 口番所で出入りを記録する。許可証がなければ潜れない
- 指揮の分散: 冒険者はパーティ単位で動き、数千人が一つにまとまる仕組みがない
- 財産の担保: 灰等級の保証金、相棒契約の登録、遺品の預かり、装備の借金
- 共通の敵: 海嘯が起きれば、全員が死ぬ。都市が滅べば、燐晶も売れない
- 封鎖令の副次機能: 武装した労働力を、迷宮に閉じ込める。入口の守りが堅いからこそ、発令の脅しが効く

**教会の教え**: 海嘯は、深淵の寝返りだと教える【未確定】。

### 15.5 兆候と警報

| 兆候 | 内容 | 信頼度 |
|---|---|---|
| 偽の曙 | 夜なのに、地平がぼんやり緑白く明るむ | 低。2303年に多発して外れた（火種19） |
| 雲の底の光 | 大穴の底の光が、雲の下面を照らして、脈打つ | 中 |
| 星の滲み | 星が一つずつ滲んで消える。空座の方角の星だけ、瞬かなくなる | 中 |
| 月の暈 | 月に、七重の暈がかかる | 低 |
| 燐の霧 | 燐晶の粉を含む霧が、地を這う。夜は薄青く光る | 高 |
| 鼠と鳥の逃走 | 洞窟鼠が地上へ逃げ出す。鳥が一斉に穴から飛び去る | 高（発生の直前） |
| 灯守の灯の変色 | 燐晶の灯が、青から白へ変わる | 中〜高 |
| 魔道具の誤動作 | 燐晶を使う灯具や秤が、勝手に光る | 中〜高 |

| 段階 | 先行時間（目安） | 兆候 |
|---|---|---|
| 予兆 | 数日〜数週間 | 偽の曙、星の滲み、月の暈 |
| 切迫 | 数時間 | 雲の底の光、燐の霧、灯守の灯の変色、魔道具の誤動作 |
| 発生 | 数分 | 鼠と鳥の逃走 |

- 暦官は、座環盤で、階級三以上が起きうる年を割り出す。兆候の観測は、灯守と口番所が担う
- 信頼度の低い予兆は、何度も外れる。信頼度の高い兆候は、切迫の段階でしか出ない
- 沈黙の夜は、鐘も灯も使えない。守備軍は無言の訓練を行い、手信号で動く（火種22）。【未確定】警報の鐘だけは、例外として鳴らしてよいか
- 【未確定】兆候の意味は、真相で変わる。A: 王の目覚めの前触れ。B: 母の疲弊（母の灯が揺れる）。C: 迷宮が声を試す
