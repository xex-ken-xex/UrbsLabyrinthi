# 迷宮都市「ヴェルガ・ノクス」プレイヤー向け資料

## 0. この資料について

- 都市の住人が常識として知っていること、調べれば分かることだけを書いています
- 噂や俗説は「噂」と明記しています。真偽は不明です
- 年代は「現在」から数えた概数です

---

## 1. 都市の概要

- **都市名**: ヴェルガ・ノクス（国家に属さない自治都市）
- **所在地**: 大陸中央の荒野。巨大な縦穴（大穴）を中心に築かれた
- **主要資源**: 燐晶（魔力を帯びた鉱石。灯火・鍛冶・魔術の触媒）。大陸の経済を左右する
- **水と食料**: 西を濯ぎ川が流れ、川沿いに畑がある。ただし食料の大半は、燐晶を売った代金で、南から買う（§14）
- **災い**: 大穴から魔物が波のように溢れる「海嘯（かいしょう）」。都市の防衛は、これに備えて組まれている（§15）
- **人口**: 数万人規模（約3万人。大海嘯前は約1.5倍）
- **暦**: 大陸共通の「座暦（ざれき）」（§5.6）。現在は座暦2352年。今年は196年に一度の「大閏（おおうるう）」の年
- **踏破済み最深層**: 第九層（約120年前）。第十層以降の帰還者はいない
- **都市の構図**: 高所ほど安全で、低所ほど迷宮の「息」（瘴気や魔物の漏出）に近い。身分差が都市の形になっている

### 1.1 都市構造（同心円状の三層）

| 層 | 呼称 | 位置 | 主な住人 |
|---|---|---|---|
| 上層 | 冠環区（クラウン） | 穴の縁より高い丘の上 | 貴族、大商人、聖職者の上位者 |
| 中層 | 縁環区（リム） | 穴の周囲の平地 | 職人、商人、下級官吏、中堅冒険者 |
| 下層 | 壁下区（ピット） | 大穴の斜面と外周の低地 | 労働者、運び屋、貧民、新人冒険者 |

### 1.2 迷宮の呼び名

迷宮は使う人によって呼び名が違う。

| 呼称 | 使う人 | 由来・意味 |
|---|---|---|
| 螺旋の胃袋（ラビリンス・スパイラル） | 採掘者、冒険者、下層民 | 最初期からの俗称。掘り進めた坑道が螺旋を描き、飲み込まれて帰らない者が多かったことから |
| ヴェルガ大迷宮 | 評議会、ギルド | 公式名。許可証や記録にはこの名前が書かれる |
| 眠りの床（ねどこ） | 静寂派（教会） | 大穴の底の「眠れる深淵」が眠る床。祈りの文言で使う |
| 玉座の階（きざはし） | 目覚めの徒 | 深淵の王のもとへ続く階段。異端の呼称で、口にすると敬遠される |
| 真の名 | 不明 | 古い文書に断片が残るという噂があるが、読み解ける者はいない |

### 1.3 都市の外郭

- **二重城壁**: 内壁と外壁がある。大海嘯のあとに築かれた
  - **内壁**: 縁環区と壁下区の境にある。大穴を囲む正七角形で、静印と同じ形。七つの角に「静印塔」が立つ。壁下区は壁の「下」、つまり大穴の側にあり、これが名前の由来
  - **外壁**: 都市の外周を囲む。荒野の魔物と、内壁が破られたときの備えを兼ねる
- **濯ぎ川**: 外壁の外、都市の西を流れる川（§14.1）
- **川畑（かわばた）**: 濯ぎ川沿いの畑。外壁の外にある（§14.2）
- **水門**: 外壁に、川の水を引き込む水門が一つある

## 2. 歴史

| 時代 | 時期 | 出来事 |
|---|---|---|
| 開闢期 | 約400年前 | 荒野に大穴が出現（隕石か遺跡崩落かは不明）。国を追われた傭兵団と盗賊の混成部隊が、浅層で燐晶を発見する |
| 採掘者の時代 | 400〜300年前 | 天幕の集落が生まれる。採掘権を巡る殺し合いが日常だった。英雄「鉄脚のオルド」が採掘者を束ね、最初の自治組織「坑口盟約」を結ぶ |
| 初海嘯 | 約340年前 | 掘りすぎで魔物が溢れ、数百人が死ぬ。採掘者が坑口に集って食い止めた。これを機に、坑口盟約が結ばれた |
| 大海嘯 | 約200年前 | 掘りすぎにより深層の魔物が地上に溢れ、一夜で人口の3分の1を失う。二重城壁、評議会、冒険者の管理制度、ギルド連合が成立する |
| 返し海嘯 | 約150年前 | 大海嘯の49年後。二重城壁が初めて試され、持ちこたえた。壁下区の一部と、守備軍・冒険者に多くの死者が出た |
| 第九層踏破 | 約120年前 | 最深到達記録。以降更新されていない |
| 目覚めの徒の台頭 | 約100年前 | 下層で異端の教えが広まり始める。教会は公に弾圧しているが、信者は絶えない。同じ頃、小規模な海嘯が起き、異端はこれを「王の目覚めの予兆」と説いた |
| 空振りの年 | 約50年前 | 海嘯の兆候が現れ、封鎖令が出されたが、海嘯は起きなかった。迷宮に取り残された冒険者数百人が死に、ギルドと評議会のあいだに遺恨が残った |
| 現代 | 現在 | 深層の探索権が最大の政治問題。燐晶供給が大陸経済を左右し、周辺諸国が動向を注視する |

## 3. 政治体制

### 3.1 九席評議会（採掘寡頭制）

| 役職 | 議席 | 役割 |
|---|---|---|
| 燐晶卿 | 3 | 燐晶の採掘・精錬・流通を握る三大商家。事実上の最大権力者 |
| 坑口守護官 | 2 | 都市防衛軍と迷宮封鎖の責任者 |
| 聖印司 | 2 | 宗教界の代表（静寂派）。民衆への影響力を持つ |
| ギルド総長 | 1 | 冒険者・職人ギルドの連合代表 |
| 民選代弁官 | 1 | 中層・下層から選ばれる唯一の庶民枠。実権は乏しい |

- 決議は多数決（過半数は5票）。燐晶卿は3票を握るため、あと2票で何でも通る
- 2票を動かす最短の道は、聖印司の2席か、坑口守護官の2席を味方にすること。これが都市政治の駆け引きの中心

### 3.2 主要制度

- **潜行許可証**: 迷宮に入るには許可証が必要。等級制で、深く潜るほど高等級が求められる。名義は評議会、審査と管理はギルド（§4）
- **燐晶税**: 持ち帰った燐晶の3割を納める。徴税官は迷宮の出口で待ち構えている。納税額の基礎となる査定は、ギルドの査定所が行う
- **封鎖令**: 海嘯の兆候があれば全入口を閉鎖する。坑口守護官が単独で緊急発令でき、72時間以内に評議会の過半数が追認しなければ解除される。封鎖中、迷宮内の冒険者は見捨てられる
- **召集義務**: 坑口盟約以来の決まり。海嘯の兆候で坑口守護官が召集をかければ、潜行許可証を持つ冒険者は、持ち場に就く。命令はギルドマスターを通して届く（§15.3）
- **相棒契約（あいぼうけいやく）**: ギルドに届け出る二人組の契約。性別も関係（恋人、親友、家族）も問わない。遺品の受取人、遺族補償金、負債の引き受けを互いに指定できる。坑夫の契り（§9）を制度にしたもの。評議会は「遺品の散逸を防ぐ制度」と説明している

## 4. 評議会とギルド

### 4.1 ギルドの組織

「坑口ギルド連合」は、複数のギルドを束ねた組織で、評議会に1席を持つ。

| 組織 | 役割 | 長 |
|---|---|---|
| 潜行者組合（通称：冒険者ギルド） | 迷宮に潜る者の登録、依頼、帰還管理、査定、捜索 | 組合長（ギルドマスター） |
| 鍛冶組 | 武具、道具の製造と修理。炉火神ヘルグの信仰が篤い | 鍛冶組長 |
| 薬師組 | 薬、解毒、治療具。治療師の組織 | 薬師組長 |
| 魔道具組 | 燐晶を使った灯具、魔道具の製造 | 魔道具組長 |
| 石工・坑道組 | 建築、坑道の補修、城壁の保守 | 石工組長 |
| 担ぎ組（非公認） | 運び屋、灯守、屑拾いの互助会。評議会はギルドとして認めていないが、黙認している | 持ち回り |

- 上の5つの組織の長が「五長老会」を構成し、そのなかから互選でギルド総長を選ぶ（任期4年、再選可）
- 総長は評議会に出る政治家、ギルドマスターは冒険者組合の実務責任者。別の人物が就く場合も、兼任する場合もある
- 現在は別の人物が就いている（§4.4）

### 4.2 冒険者ギルドの運営

**本部と拠点**
- 本部は縁環区の大穴の縁に建つ「坑口館（こうこうかん）」
- 壁下区に「底支部」、冠環区に連絡所、迷宮の各入口に「口番所」（出入りの記録所）を置く

**部署**

| 部署 | 仕事 |
|---|---|
| 受付課 | 登録、依頼の仲介、パーティ編成の支援 |
| 査定課 | 燐晶と魔物素材の査定。納税額の基礎になる |
| 帰還記録課 | 潜行前の届出と帰還の記録。期日を過ぎた者の洗い出し |
| 遺品課 | 遺品の保管、相棒契約の届出と払い出し |
| 捜索課 | 有料の捜索隊「灯手（ともし）隊」の派遣 |
| 監察課 | 規約違反、パーティ内の不正、殺人の調査 |
| 講習課 | 新人講習、昇級審査の試験 |

**収入源**
- 依頼の仲介手数料（報酬の約1割）
- 許可証の審査料と年次の更新料
- 灰等級の保証金の運用益
- 燐晶と素材の査定手数料
- 遺品の保管料、捜索隊の派遣料
- 評議会からの委託費（出入口の記録業務）

**運営の決まり**
- 潜行前に予定を届け出る。期日までに戻らなければ、捜索隊が有料で出る（積立の保険「帰還積立」に入っていれば無料）
- 昇級は実績、推薦、審査試験で決まる。審査はギルド、許可証の発行は評議会名義で、署名はギルドマスターが行う
- 封鎖令の期間中は、捜索隊を出すことが禁じられる

### 4.3 評議会との関係

**権限の分担**

| 事項 | 評議会 | ギルド |
|---|---|---|
| 潜行許可証 | 発行権（名義と印） | 審査、推薦、更新、記録の管理 |
| 燐晶税 | 税率の決定と徴収（徴税官） | 査定（税の基礎となる量と純度） |
| 封鎖令 | 発令と追認 | 意見の具申、閉鎖時の冒険者名簿の提出 |
| 迷宮の治安 | 坑口守護官の軍が出入口と浅層を警備 | 層内は冒険者の自己責任 |
| 救助 | 公式には行わない | 有料の捜索隊 |
| 遺品と補償 | 補償金の支給規則 | 管理と払い出し |

**成り立ち**
ギルド連合は、坑口盟約を受け継ぐ組織。大海嘯のあと評議会が成立するとき、「採掘者の自治を残す」ことを条件に1席を得た。条文のひとつに「帰還の記録はギルドが独自に保持する」とあり、評議会が手を出せない数少ない領分になっている。

**緊張関係**
- 評議会は、許可証と封鎖令でギルドを押さえている
- ギルドは、査定と帰還記録という「情報」で評議会に対抗している
- 燐晶卿は、査定を握るギルドを疎ましく思っている
- 総長は1票しか持たないが、評議会が割れたとき「最後の1票」になりうる

**連携しやすい相手**
- 坑口守護官: 封鎖令で冒険者を見捨てる判断に、現場の軍人が苦い顔をしている
- 民選代弁官: 庶民枠どうしで利害が近い
- 聖印司: 死者の弔いで日常的に接点がある

### 4.4 名の知られた人物

- **ギルドマスター「セラ・ブランデル」**: 40代の女性。元・銀等級の叩き上げ。現場の冒険者からの信頼が厚い。引退の理由は、膝の負傷
- **ギルド総長「ドルガ・イーセン」**: 60代の男性。鍛冶組長が本職。職人に顔が利く保守派。評議会ではあまり発言しない

## 5. 宗教

### 5.1 大陸の信仰「十二座の神々」

大陸で最も広く信じられる多神教。国や地域によって神殿の規模や教義は違うが、「十二の座に神々が座す」という世界観は共通している。

| 座 | 神 | 司るもの | ヴェルガ・ノクスでの信仰 |
|---|---|---|---|
| 一 | 天秩の王「アウレオン」 | 天空、法、王権 | 貴族、評議会の議員 |
| 二 | 大地の母「ターナ」 | 大地、豊穣、出産 | 農村から来た移民、産婆 |
| 三 | 炉火の神「ヘルグ」 | 火、鍛冶、職人 | 職人ギルド、特に鍛冶組 |
| 四 | 潮路の神「ナウラ」 | 海、旅、商い | 商人、他国から来た交易者 |
| 五 | 誓剣の神「ガロウ」 | 戦、誓約、守護 | 坑口守護官の軍、冒険者の誓い |
| 六 | 星録の女神「サフィア」 | 知識、文字、暦、星 | 写本師、書記、地図師 |
| 七 | 癒しの神「イリン」 | 治癒、薬、清め | 治療師、薬師組 |
| 八 | 荒野の狩人「アルク」 | 狩り、荒野、獣 | 荒野を渡る隊商、猟師 |
| 九 | 灯火の女神「ルシュカ」 | 愛、酒、歓楽、灯 | 色街、酒場の主人 |
| 十 | 賽の神「ハザル」 | 運、賭け、偶然 | 下層の賭場、運び屋 |
| 十一 | 静寂の母「シレンティア」 | 眠り、夜、沈黙、死者の安息 | 全層（特に冒険者と遺族） |
| 十二 | 空座（くうざ） | 不明 | 後述 |

**空座**
十二の座のうち、最後のひとつには神が座っていない。どの神殿でも、空の玉座として描かれる。去った神、追放された神、まだ生まれていない神、眠れる神など、教派によって解釈が分かれる。

### 5.2 静寂の母シレンティアと静寂派

**大陸での姿**
眠りと夜と死者の安息を司る女神。葬儀、産褥、不眠の夜に祈られる。死は誰にも訪れるため、神殿は大陸のほぼすべての都市にあり、信徒数は十二座のなかでも上位に入る。大陸の静寂派は、人々の眠りと死者の安息を守る穏やかな宗派。

**ヴェルガ・ノクスの静寂派**
この都市の静寂派は、大陸でも特に影響力が強い。理由は、迷宮との結びつきにある。

- 大海嘯を鎮めたのは静寂の母だと伝えられている
- 大穴の底に「眠れる深淵」があり、静寂の母が子守唄で眠らせ続けていると信じられている
- 教義の核心は「穴を起こすな」
- 都市の教会は「聖印司」を名乗り、評議会に2席を持つ
- 冒険者に祝福の「静印」を授けて寄進を受ける。静印は大陸中の冒険者に知られており、他の迷宮都市にも輸出されている
- 迷宮探索は必要悪として容認するが、深層への挑戦は禁じる

この「穴を起こすな」の教えは、ヴェルガの静寂派に特有のもの。他の地域の静寂派は、これを「迷宮の都市の地方教義」と見て、一定の距離を置いている。それでも、ヴェルガの聖印司の寄進は大陸の静寂派の財政を支えており、無視できない存在。

### 5.3 都市の宗派と神殿

| 名称 | 分類 | 要点 |
|---|---|---|
| 静寂派（聖印司） | 公式主流派 | 上記の通り。都市で最大の勢力 |
| 炉火の神殿 | 十二座 | 鍛冶組と結びつきが強く、職人の守護神。評議会とも距離が近い |
| 灯火の神殿 | 十二座 | 色街の守護者。酒場、娼館、帰還祝いの宴の守り神。静寂派とは緩やかに提携している |
| 星録の書院 | 十二座 | 写本、暦、地図の組織。教会の写本室とは別に独立した書庫を持つ |
| 賽の祠 | 十二座 | 下層の賭場に併設された小さな祠。信徒は多いが、組織はない |
| 癒しの院 | 十二座 | 治療師の施設。静寂派の葬儀と協力関係にある |
| 誓剣の詰所 | 十二座 | 坑口守護官の軍に付属する礼拝所 |
| 目覚めの徒 | 異端教団 | 空座の主は迷宮の底に眠っており、目覚めを待つ王だと説く。下層民と一部の冒険者に信徒が多い。教会は公に弾圧している |
| 坑夫の聖人信仰 | 民間信仰 | 鉄脚のオルドら歴代の英雄を祀る。下層民が日々の安全を祈る、最も身近な信仰 |

### 5.4 子守唄「静寂の七息」

- 静寂の母が深淵に歌うとされる、七節の子守唄
- 教会が教義の中心に据えている。教会写本版が公式版
- 節ごとの「息継ぎ」に意味があるとされるが、詳しくは教会の内部でも一部の者しか知らない
- 坑夫のあいだには、第六節だけ歌詞が違う労働歌版が流布している
- 噂: 教会が公開していない、古い版の子守唄があるという

### 5.5 印

- **静印**（教会）: 正七角形。完全な囲い、つまり封印を意味する
- **七芒星**: 目覚めの徒の印。開かれた門を意味する。教会では異端の印とされ、掲げると罰される
- **七七夜**: 49夜。葬送の習慣で、死者の魂が去る日とされる。大陸の静寂派に共通する（§5.6）

### 5.6 座暦（ざれき）

大陸のどこでも同じ暦。十二座の神々が座に就いた日を元年とし、太古から受け継がれている。星録の女神サフィアの神殿が告示し、「暦官」が管理する。国や王が別に定める暦（即位年など）もあるが、神事、農事、商い、弔いは座暦で行う。現在は**座暦2352年**。

子どもは、神殿へ参るときに、神官から次のことを習う。

**1. 夜、節、巡り**
- 日は「夜」で数える
- 7夜で「一巡り」。子守唄「静寂の七息」を一曲歌い終える長さ。巡りの夜には、第一節の夜〜第七節の夜の名が付く

**2. 十二座の月**
- 1月は30夜。月ごとに十二座が順に守護する
- 12の月は次の通り

| 月 | 守護 | 季節と習わし |
|---|---|---|
| 1 | 天秩の王 | 新年。法と誓約を更新する |
| 2 | 大地の母 | 種まきの月。産婆の月 |
| 3 | 炉火の神 | 炉開き（初日）。徒弟が職人になる |
| 4 | 潮路の神 | 航海と市の始まり |
| 5 | 誓剣の神 | 婚礼と誓いの月 |
| 6 | 星録の女神 | 暦官の告示、書院の公開 |
| 7 | 癒しの神 | 暑さの病に備える |
| 8 | 荒野の狩人 | 狩猟と隊商の最盛期 |
| 9 | 灯火の女神 | 灯祭。色街と酒場に灯りがともる |
| 10 | 賽の神 | 年の市、賭場の祭り |
| 11 | 静寂の母 | 夜が長い月。弔いの月 |
| 12 | 空座 | 守護する神がいない月。願い事をしない |

**3. 座渡し（ざわたし）**
- 12月のあとに、月に属さない5夜がある。これで1年は365夜になる
- 第一夜が「座降ろし」。神々が座を降りる夜（ヴェルガ・ノクスでは「沈黙の夜」）
- 次の三夜は「母の三夜」。静寂の母が世界を預かる
- 第五夜が「座昇り」。神々が座に戻り、新しい年が始まる

**4. 七七夜（ななななよ）**
- 7巡り＝49夜。人は二度、七七夜を迎える
  - 生まれて49夜目に、神殿へ披露する
  - 死んで49夜目に、魂を送る

**5. 七七年と大閏**
- 暦は49年で元に戻る。これを「七七年」と呼ぶ
- 196年（七七年の4つ分）に一度、「大閏」がある。空座の月が49夜延びて、79夜になる。延びた49夜は「空座の七七夜」と呼ばれ、神々の座が空く期間とされる
- 大閏のたびに、十二座が順に「番」を務める。第一の大閏は天秩の王、第十一は静寂の母、第十二は空座の番。十二座が一巡する2352年で、座暦は一巡りする
- **今年は第十二の大閏、空座の番にあたる**。空座の月が30夜で終わらず、31夜目へ続くことは、暦官が何年も前から告げてきた
- 前回の大閏は196年前。ヴェルガ・ノクスでは、大海嘯の年と重なると伝わる。静寂派は、これを静寂の母の番だったと教える
- 空座の番に誰を祀るのかは、神殿のあいだで意見が割れている

**6. 覚え歌**

> 月は三十、座は十二
> 七夜で一曲、七曲で七七夜
> 年の暮れには座渡し五夜
> 年ごとに、一節進んで三曲一夜
> 七七年で巡り戻る

- 「年ごとに、一節進んで三曲一夜」は、年が替わるたびに、節の夜は1つ、七七夜は3巡りと1夜ずつ進むという意味

**7. 座暦碑**
- 暦を刻んだ十二枚の石碑が、星録の神殿に伝わる。十二枚目だけは、太古から白紙のまま

**暦官と座環盤**
- 暦官は、「座環盤（ざかんばん）」という手回しの計算盤を使い、暦の重なりや大閏を割り出す
- 座環盤は、歯車を回せば誰でも使えるが、なぜ49年で元に戻るのかを説明できる暦官は、ごく少数

### 5.7 祭礼

- **沈黙の夜**: 年の終わりの座降ろしの夜。大海嘯が起きた夜だったと伝わる。全市民が日没から夜明けまで音を立てず、灯りを消して過ごす。深淵を起こさないための儀式。この夜は犯罪も最多発する
- **灯祭**: 灯火の月（9月）の祭り。灯火の女神に捧げる。色街と酒場が一斉に色とりどりの灯りをともす
- **炉開き**: 炉火の月（3月）の初日の祭り。炉火の神に捧げる。職人ギルドの行事で、徒弟が正式な職人として認められる

## 6. 迷宮

### 6.1 層構造

| 層 | 呼称 | 環境 | 代表的なモンスター |
|---|---|---|---|
| 第1〜2層 | 腐葉の回廊 | 湿った洞窟、苔と茸 | 洞窟鼠、粘泥（スライム）、骨亡者 |
| 第3〜4層 | 錆鉄の坑道 | 古い採掘坑道の廃墟 | 鉱喰い蟲、坑道の亡霊、鎧鬼 |
| 第5〜6層 | 鏡の水廊 | 地下水と反射する壁 | 水蛇、鏡像獣（冒険者の姿を模倣する） |
| 第7〜9層 | 骨の大聖堂 | 巨大な骨の構造物 | 骨の守護者、嘆きの聖歌隊、黒蝕の騎士 |
| 第10層以降 | 不明 | 帰還者なし | 「胃袋の主」の噂のみ |

### 6.2 迷宮の特性

- **動く壁**: 毎夜、通路の構造が少しずつ変わる。地図は数日で無効になる
- **燐晶の成長**: 魔物の死骸や冒険者の血を養分に育つと言われる。深層ほど純度が高い
- **呼吸**: 周期的に「吸う」「吐く」を繰り返す。吐く時期は魔物が活発になる。周期は、長いもの（数か月〜数年）と、夜ごとの短いものがある

### 6.3 大陸の他の大迷宮

大陸には、規模と歴史で知られる「大迷宮」が五つある。ヴェルガ大迷宮はそのひとつ。このほかに、小規模な迷宮は数十あり、多くは名前もない。

| 名称 | 所在 | 特徴 | 主な産出 | 関わりの深い信仰 |
|---|---|---|---|---|
| ヴェルガ大迷宮 | 大陸中央の荒野 | 縦穴を降りる。通路が毎夜変わる | 燐晶 | 静寂派 |
| 凍てつく書庫（フロスト・アーカイヴ） | 北方の氷原 | 氷の下に広がる書架の迷路。書架が動く | 古文書、魔導書、氷晶 | 星録の女神 |
| 黄金の墳墓群（サンド・ネクロポリス） | 東の砂漠 | 王墓の連なり。砂が通路を埋め替える | 古代遺物、金 | 天秩の王 |
| 潮の回廊（ティダル・コリドー） | 南の海岸 | 干満で水没と露出を繰り返す海蝕洞 | 真珠、潮晶 | 潮路の神 |
| 根の迷宮（ルート・メイズ） | 西の大森林 | 巨木の根が成長して道を作り替える | 薬草、霊薬の素材、獣素材 | 大地の母、荒野の狩人 |

**迷宮どうしの関係**
- **交易**: 産出物が補い合う関係。燐晶は大陸全土の灯火と鍛冶に使われ、他の迷宮の産出物と交換される。ヴェルガは燐晶の輸出で大陸経済を左右する
- **冒険者の往来**: 大迷宮を巡る冒険者が一定数いる。等級は都市ごとの相互承認制で、ヴェルガの「灰」は他都市の「青銅」相当と言われる。ヴェルガの黒鉄は、どこでも一目置かれる
- **共通点**: どの大迷宮も、通路や構造が何らかの形で「動く」。どれも呼吸のように、活発な時期と静かな時期を繰り返す
- **学者の説**
  - 十二座の神々に対応して、十二の大迷宮があるはずだ（確認されているのは五つ）
  - 大迷宮は地下深くでつながっている（迷宮で行方不明になった者が、別の迷宮で見つかった、という記録がわずかにある）
  - 大迷宮は神々の不在の痕である
  - いずれも確証はない

### 7.2 冒険者の現実

- 手元に残る報酬は3割に届かない（装備維持費、ギルド手数料、燐晶税）
- 新人の死因の最多は、魔物ではなく、パーティ内の裏切りと遺品目当ての殺害
- 引退できるのは1割以下。多くは負傷による廃業か死亡
- 黒鉄級でも、封鎖令で見捨てられる

### 7.3 迷宮の職業

- **地図師**: 迷宮の構造を記録し、地図として売る。通路が毎夜変わるため、「当日の斥候地図」か「層ごとの大まかな案内図」が中心。ギルドは地図の信頼性を管理している
- **灯守（ランタン守）**: 迷宮の浅層の通路で灯りを維持する。下層の仕事（§8.1）
- **運び屋（ポーター）**: 冒険者の荷物と戦利品を担ぐ。下層の仕事（§8.1）

## 8. 庶民の生活

### 8.1 下層民（壁下区）

- **住環境**: 大穴の斜面に、廃材と坑道の残骸で組まれた掘っ立て小屋が段々に積み重なる。下の段ほど瘴気が濃い。慢性の咳「煤吐き」を、自嘲気味に「ピットの挨拶」と呼ぶ
- **仕事**
  - 運び屋: 最も一般的。日当は銀貨数枚
  - 屑拾い: 捨てられた装備や魔物の素材を拾う
  - 灯守: 浅層の灯りを維持する。魔物に襲われる危険がある
  - 死体洗い: 遺体を清め、遺品を届ける。感謝される一方、忌み嫌われる
- **食**: 燐晶の副産物の灰で育てる黒い茸、川畑で採れる灰芋、魔物肉の煮込み「胃袋スープ」。食の階層は §14.3
- **娯楽**: 冒険者の生還・死亡を賭ける賭博。「今夜あの一行は何人戻るか」に銅貨が飛び交う
- **希望と現実**: 夢は許可証を得て冒険者になること。許可証には保証金と推薦人が必要で、貧民には難しい。無許可の「闇潜り」が横行し、毎年多くの若者が死ぬ
- 灯守は、迷宮の息の変化に最初に気づく立場にいる。異変の第一報はたいてい灯守から出る

### 8.2 中層民（縁環区）

- **住環境**: 石造り三〜四階建て。一階が店、上階が住居。道は狭く、荷車と人で混雑している。各区画に防壁と鐘楼があり、魔物の漏出時は鐘が鳴り、住民は地下室へ避難する
- **仕事**
  - 職人: ギルド所属。徒弟制度が厳格
  - 商人: 装備、保存食、治療薬を扱う。景気は迷宮に直結する
  - 官吏: 許可証の発行、徴税、記録を担当する下級役人。賄賂が収入の大半という者もいる
  - 中堅冒険者: 第3〜5層で安定して稼ぐ。家庭を持つ者も多いが、引退できずに潜り続ける
- **不安**: 「いつ下層に落ちるか」「いつ封鎖令が出るか」。燐晶の価格が下がれば店が潰れ、海嘯の予兆があれば物価が急騰する
- **文化**: ギルドの酒場が社交の中心
  - 帰還祝い: 生還者が奢る宴
  - 空席の杯: 帰らなかった仲間の席と杯を、必ず用意する

## 9. 色街「寝息通り（ねいきどおり）」

縁環区と壁下区の境に伸びる通り。迷宮の「息」に対して、人の寝息の通りと呼ばれる。娼館、酒場、連れ込み宿、治療師、占い師が並び、都市で最も灯りが消えない場所。

### 9.1 基本

- **客層**: 圧倒的に冒険者。帰還した夜に生を確かめる習慣が、「帰還祝い」の延長として根づいている
- **婉曲**: 娼館は「眠りの家」と呼ばれる。守護は灯火の女神。静寂派は公式には黙認し、静印の寄進と引き換えに営業を事実上認めている
- **法**: 営業は成人のみ。無許可営業と、客や従業員への暴力は、評議会の風紀官が取り締まる。実効性は区による
- **性の扱い**: 都市全体として、同性愛や男娼に対する偏見は薄い。問題にされるのは身分差と金の流れで、相手の性別ではない
- **坑夫の契り**: 開闢期、男だけの採掘団では、坑内で二人一組を組み、互いを命綱とする習慣があった。同性の恋愛が普通にあり、組の片方が死ぬと、もう片方が遺品と名を引き継いだ。この習慣が文化として残り、制度化されたものが相棒契約（§3.2）。冒険者のあいだで「相棒」という言葉は、恋人とほぼ同義に使われる

### 9.2 館の種類

| 区分 | 呼称 | 位置 | 客層・特徴 |
|---|---|---|---|
| 下層 | 穴蔵屋 | 壁下区側 | 安価。瘴気と煤吐きの病が絶えない。闇潜りの失敗者や、許可証を失った冒険者が最後に流れ着く |
| 中層 | 帰還亭 | 通りの中央 | 冒険者向けの標準的な館。男性向け、女性向け、男同士・女同士に対応する店が混在する |
| 中層 | 双つ鏡亭 | 縁環区側 | 男性同士の客に特化した高級店。鏡張りの部屋が売りで、中層の商人や官吏も通う |
| 上層 | 冠館（かんむりやかた） | 冠環区 | 貴族と大商人の会員制。接客に加え、密談、取引、情報交換の場として使われる |

### 9.3 風習

- **灯の色**: 灯りの色が客層を示す。橙は男女、青は男同士、白は女同士、赤は何でも。色を組み合わせて細かく変える店もある
- **初灯（はつひ）**: 迷宮から戻った冒険者が最初に入る店。縁起を担ぎ、決まった店に通う冒険者が多い
- **空席の杯**: 館にも置く。亡くなった常連の分の杯を、ずっと残す店がある
- **沈黙の夜**: この夜だけは、館も灯りを消し、声を出さずに営業する。禁じられているわけではないため、他の夜より客が多い

### 9.4 名の知られた人物

- **双つ鏡亭の館主「レオン・ハイド」**: 元・黒鉄級冒険者。かつての相棒を第七層で亡くした。今は店を切り盛りしながら、冒険者に迷宮の助言をすることもある
- **帰還亭の看板「ミレイ」**: 女性。冒険者の初灯として知られる。客の生還率が妙に高いことから、縁起担ぎの対象になっている

## 14. 川・農地・経済

### 14.1 濯ぎ川（すすぎがわ）

- 鐘ヶ淵の湧水を源に、東へ約1日流れて、都市の西側（外壁の外の低地）を通る川。畑と都市で水を使い切るため、下流はない。水は南西の砂礫地で地下へ消える
- 水は灰と燐晶の気を含んで硬い。そのまま飲む者はおらず、煮沸してから使う
- 使い道は、洗鉱、精錬の冷却、死体洗いと遺体の浄め、畑の灌漑。荷舟が通えるのは、短い区間だけ
- 外壁の水門は、坑口守護官に属する水門守が守る。畑に水を配る順番も、水門守が決める
- 七七夜の葬列は、川沿いを西へ遡って鐘ヶ淵へ向かう。「死者は上り、水は下る」という言い方がある
- 灰堰砦の涸れ谷は、昔は川が流れていた跡だと言われる

### 14.2 川畑（かわばた）

- 濯ぎ川の下流に、帯状に畑が広がる。長さは約10km、幅は2〜3km、広さは約1,000ha。農村が三〜四つあり、耕作者は家族を含めて約2,000人
- 荒野は雨が少なく、川の水を引ける畑のほかでは、麦が育たない
- 作物は、大麦、灰芋、豆、蕪、キャベツ。小麦はわずか
- 播種は2月（大地の母の月）、麦の収穫は8〜9月、芋は10月。10月の年の市は、収穫市を兼ねる
- 畑は外壁の外にあるため、海嘯のときは、最初に危うくなる
- 畑で賄えるのは、都市の食料のうち、二〜三割ほど。残りは輸入に頼る

### 14.3 食の階層

| 層 | 主な食べ物 |
|---|---|
| 上層（冠環区） | 輸入小麦の白パン、葡萄酒、肉 |
| 中層（縁環区） | 大麦のパン、野菜、干し魚、麦酒 |
| 下層（壁下区） | 灰芋、黒い茸、胃袋スープ |

灰芋は腐りやすく、遠くへ運べない。壁下区の近くの畑で採れたものが、そのまま食卓に上る。

### 14.4 産業と交易

都市は、燐晶を売って、食料を買う。荒野では、ほとんどのものが買わなければ手に入らない。

| 売るもの | 内容 |
|---|---|
| 燐晶 | 原料と精錬品。輸出の中心 |
| 加工品 | 灯具、魔道具、鋼の武具、ガラス。荒野には薪がないため、燐晶を燃料にして作る |
| 迷宮の産物 | 魔物素材、薬、古代遺物 |
| サービス | 為替、倉庫、保険、燐晶の相場。静印、写本、暦の告示 |

| 買うもの | 内容 |
|---|---|
| 穀物 | 食料の大半。小麦、大麦 |
| 建材・燃料 | 木材、薪（石は都市で採れる） |
| 衣類 | 布、革 |
| 日用品 | 塩、油、酒、香辛料 |
| 原料 | 金属、ガラスの原料、紙、薬草 |
| 奢侈品 | 絹、宝飾、上等の葡萄酒 |

- **経路**: 取引の九割は、南街道から灰堰砦の関を通って、港へ出る。港から先は、船で各地へ向かう
- 東（砂漠）、北（氷原）、西（森）の直路は細い。古文書や古代遺物、霊薬の素材のような、軽くて高価な品しか、成り立たない
- 荷車は、満載で都市に着き、ほぼ空で帰る。往復の運賃が荷に乗るため、荒野の物価は、産地の約2倍になる
- 評議会の収入は、燐晶税と、取引にかかる関税・市場税
- 冒険者は、登録者が約3,000人。毎年、国中から若者が流れ込み、その大半が、1年以内に辞めるか、死ぬ。迷宮での死者は、年に1,000人前後。遺体の多くは、鐘ヶ淵の枕ヶ原に葬られる

## 15. 海嘯と防衛

### 15.1 海嘯（かいしょう）

大穴から魔物が、波のように地上へ溢れる災い。反乱と紛らわしいので、「氾濫」とは呼ばない。

| 階級 | 名 | 規模（推計） | 頻度 |
|---|---|---|---|
| 一 | さざ波 | 魔物が約200体まで | 年に数回。口番所と守備軍が片づける |
| 二 | うねり | 約2,000体 | 十数年に一度。壁下区に被害が出る |
| 三 | 小海嘯 | 約7,000体 | 約50年に一度 |
| 四 | 海嘯 | 約2万体 | 約100年に一度 |
| 五 | 大海嘯 | 5万体を超える | 約200年に一度 |

- 階級三以上の海嘯は、座暦が49の倍数の年にしか起きない。暦官は、この年を警戒する
- 今年（座暦2352年）は、49の倍数であり、大閏でもある。暦官は、大海嘯に警戒するよう告げている。ただし、約50年前の空振り以来、警報を疑う声も強い

### 15.3 指揮と権力の分散

- **統帥**は、坑口守護官の二席が務める。二人の意見が割れれば、動きが遅れ、被害が増える
- 燐晶卿の私兵は、守護官から独立している。ただし、海嘯のときは、共同防衛の義務がある
- 護印団は、聖印司が指揮する。こちらも、共同防衛の義務がある
- 冒険者への命令は、ギルドマスターを経由して届く
- 平時の持ち場の割り当ては、坑口守護官が決める
- 坑口守護官は、封鎖令という大きな権限を持つ。内乱を恐れて、評議会は、権限を分散させてきた。軍、私兵、僧兵、冒険者が、それぞれ別の指揮系統にあるのは、そのため

### 15.4 海嘯の兆候と警報
