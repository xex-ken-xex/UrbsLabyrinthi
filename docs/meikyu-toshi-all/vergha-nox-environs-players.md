# 迷宮都市「ヴェルガ・ノクス」周辺拠点 プレイヤー向け資料

## 0. この資料について

- ヴェルガ・ノクスの住人や、街道を行き来する者が知っていることだけを書いています
- 噂や俗説は「噂」と明記しています。真偽は不明です
- 距離は、荷を背負って歩いた場合の日数です

---

## 1. 周辺の概要

- ヴェルガ・ノクスは荒野の真ん中にある。荒野は雨が少なく、川の水を引ける畑のほかでは麦が育たない。穀物の大半は、隊商が南から運んでくる（都市資料§14）
- 鐘ヶ淵の湧水が、濯ぎ川の源。川は東へ約1日流れて、ヴェルガ・ノクスの西を通り、川沿いの畑を潤す（都市資料§14.1）
- 街道は四方へ伸びるが、道として整っているのは、海へ向かう南街道だけ
- 都市の評議会の権限が及ぶのは、原則として二重城壁の内側まで。壁の外の拠点は、それぞれ別の主を持つか、主を持たない
- 例外は灰山（§4）。評議会は「都市の灰捨て場は都市の土地」と主張しており、ふもとの下灯村には徴税官と風紀官を送る。村はこの言い分を認めていない

| 拠点 | 種別 | 位置 | 規模 | ひとことで |
|---|---|---|---|---|
| 灰堰砦（はいぜきとりで） | 城塞と宿場 | 南街道を2日。荒野の南の出口 | 守備兵 約300、城下 約500 | 燐晶の隊商が必ず通る関 |
| 鐘ヶ淵（かねがふち） | 門前町 | 西へ1日。荒野の湧水地 | 約2,000 | ヴェルガの死者が眠る、弔いの町 |
| 下灯村（しもびむら） | 村 | 北東へ半日。古い灰捨て場のふもと | 約300 | 朝まで灯を消さない、茸と担ぎ手の村 |
| 凪見の里（なぎみのさと） | 村 | 北へ3日。街道なし | 100足らず | 誰とも関わらない湖畔の里 |

## 2. 灰堰砦

### 2.1 基本

- **所属**: 南のサーレン王国の辺境の砦。城代が治める
- **成り立ち**: 大海嘯のあと、魔物が荒野を越えて南へ下ることを恐れた王国が築いた。「灰堰」は、灰色の荒野に置いた堰という意味
- **構え**: 涸れ谷の両岸を城壁でつなぎ、南街道はその門を通るしかない。弩と投石機は北、つまり都市の側を向いている涸れ谷は、昔は川が流れていた跡と言われる
- **城下**: 門の南側に宿場がある。隊商宿、両替商、護衛の口入れ屋、荒野の狩人アルクの祠、潮路の神ナウラの小神殿が並ぶ
- **水**: 城下の水は、涸れ谷の底の井戸でまかなう

### 2.2 ヴェルガ・ノクスとの関わり

- **関銭**: 燐晶を積んだ荷は、門で関銭を払う。都市の燐晶税（都市資料§3.2）とは別に取られる。関では、砦が自前の「試し石」で純度を確かめる
- **狼煙**: 砦と都市の外城壁のあいだに、六基の狼煙台が並ぶ。毎日、日没に「異状なし」の白煙を送り合う
- **堰の掟**: 都市の側から黒煙が上がれば、門を閉じる。門の北にいる者は、隊商も避難民も通さない。冒険者はこれを「外の封鎖令」と呼ぶ
- 燐晶卿は関銭を疎ましく思っているが、海へ出る道はここしかない

### 2.3 今年の様子

- 前回の大閏が大海嘯の年と重なることは、砦でも知られている。年の初めから、兵が増えている
- 空座の月が近づくにつれ、南へ発つ商人と、関で足止めされる荷が増えている

### 2.4 名の知られた人物

- **城代「ヴェルナ・ハイゼク」**: 40代の女性。王国の騎士。愛想はないが、関銭と掟を誰に対しても同じに扱うことで知られる
- **関守頭「ヨアン・デルク」**: 50代の男性。門を通る荷を、すべて台帳に付ける。数字に細かい

## 3. 鐘ヶ淵

### 3.1 基本

- 荒野では珍しい湧水の淵のほとりにある、静寂派の門前町。中心は「淵の院」
- 淵の湧水は、濯ぎ川の源。流れ出す水は東へ向かい、ヴェルガ・ノクスの西を通る（都市資料§14.1）
- 大陸の静寂派の流れを汲む。ヴェルガ・ノクスの聖印司と同じ女神を祀るが、別の組織で、「穴を起こすな」の教えは説かない（都市資料§5.2）
- 町の仕事は、墓守、墓石を刻む石工、宿坊、蝋燭づくり、弔いの記録の書き役

### 3.2 名の由来

- 淵の底に、鐘が沈んでいる。大海嘯の夜に鳴り続けた警鐘を、二度と鳴らないように沈めたと伝わる
- 町に鐘はない。刻（とき）は、院の屋根に掲げる灯の数で知らせる
- 院のなかでは声を慎む。大事な話し合いは「淵の間」で、筆談で行う習わしがある

### 3.3 弔いの町

- **枕ヶ原（まくらがはら）**: 町の西に広がる墓地。墓石を「枕石」と呼ぶ。大海嘯の死者を葬ったことに始まる
- 都市には墓地にする土地が乏しいため、ヴェルガ・ノクスで死んだ者の多くが、いまもここに葬られる
- 遺体が戻らなかった者にも、名だけを刻んだ枕石を置く
- **七七夜**: 死後49夜目の魂送り（都市資料§5.6）。遺族は葬列を組み、濯ぎ川に沿って西へ1日遡り、院で営む。弔いの月（11月）は、町が人であふれる
- **名送り帳**: 七七夜を営んだ死者の名を、院が書き留めた帳面。遺族なら誰でも見せてもらえる

### 3.4 ヴェルガ・ノクスとの関わり

- 聖印司は、淵の院に毎年寄進をしている。院の修繕も宿坊も、その金で成り立っている
- 院は、深層への挑戦を禁じない。静印も授けない。授けるのは、死者のための祈りだけ
- 聖印司の異端審問官は、鐘ヶ淵では取り締まりの権限を持たない
- ギルドの遺品課と、癒しの院の者が、遺体の搬送と弔いの手配で日常的に行き来する

### 3.5 今年の様子

- 空座の番に誰を祀るかについて、淵の院は「母の三夜と同じく、静寂の母が預かる」と説いている
- 空座の七七夜のあいだ、院は毎夜の夜伽（よとぎ）を行うと告げている

### 3.6 名の知られた人物

- **院長「マルタ・ユーレ」**: 60代の女性。穏やかで、誰の弔いも断らない
- **墓守頭「ベック」**: 50代の男性。枕ヶ原のどこに誰が眠るかを、帳面なしで覚えている

## 4. 下灯村

### 4.1 基本

- 「灰山（はいやま）」のふもとの村。灰山は、燐晶の精錬で出た灰と滓の、古い捨て場
- 大海嘯のあと、都市へ戻らなかった坑夫たちが住み着いたのが始まりと伝わる
- 坑夫の聖人信仰（都市資料§5.3）が篤く、鉄脚のオルドの祠がある

### 4.2 暮らし

- **黒い茸**: 灰山の灰で育て、壁下区へ卸す（都市資料§8.1）。壁下区の食卓に上る茸のかなりの部分は、この村のもの
- **担ぎ手**: 若者の多くは都市へ出て、運び屋や灯守になる。担ぎ組との縁が深い
- **灯**: どの家も、日没から夜明けまで軒の灯を消さない。坑夫の労働歌の第六節「母よ見ていて、朝まで灯を」に由来すると言われる
- **沈黙の夜**: 声は立てないが、灯だけは消さない。聖印司は、これを快く思っていない

### 4.3 ヴェルガ・ノクスとの関わり

- 茸を積んだ荷駄が、毎朝、都市の壁下区へ向かう
- 徴税官と風紀官が、ときどき村を調べに来る。何を調べているのかは語られない

### 4.4 名の知られた人物

- **世話役「トーヤ」**: 高齢の女性。元・死体洗い。村の決め事は、彼女の家の土間で決まる
- **荷駄頭「ガラン」**: 40代の男性。元・運び屋。茸の荷を都市へ運ぶ荷駄を仕切る

## 5. 凪見の里

- 街道はなく、荒野の狩人か猟師の案内がなければ辿り着けない。都市では、名前を知る者も少ない
- 風のない日に空を映す、丸い湖のほとりにある。漁と、わずかな畑と、山羊で暮らす
- どの国にも都市にも、税を納めていない
- 信仰は、大地の母ターナと荒野の狩人アルク。小さな祠があるだけで、神官はいない。暦は座暦に従う
- 燐晶を使わない。灯りは獣脂。理由を訊いても「昔からの決まり」としか答えない
- 外との行き来は、年に2回来る塩の行商だけ
- 迷宮にも、都市の政治にも関心がない
- **里長「ハンナ」**: 50代の女性。よそ者を追い返しはしないが、長居も勧めない

## 6. 拠点どうしの関係

| 組み合わせ | 関係 |
|---|---|
| 灰堰砦 ⇔ ヴェルガ・ノクス | 燐晶の関銭と、毎日の狼煙。互いに頼り、互いに疎んでいる |
| 鐘ヶ淵 ⇔ ヴェルガ・ノクス | 死者の弔いと、聖印司の寄進。同じ女神を祀るが、教えは違う |
| 下灯村 ⇔ ヴェルガ・ノクス | 茸と担ぎ手を送り出す。聖印司と徴税官には睨まれている |
| 灰堰砦 ⇔ 鐘ヶ淵 | 砦の兵も枕ヶ原に葬られる。評議会の使者と砦の使者が会うときは、淵の間を使う |
| 鐘ヶ淵 ⇔ 下灯村 | 院は村の死者を無償で弔う。闇潜りで死んだ者も断らない |
| 灰堰砦 ⇔ 下灯村 | 表向きの関わりはない |
| 凪見の里 | どことも関わりがない |

## 7. 街道の噂（真偽不明）

- 灰堰砦の兵が増えているのは、海嘯に備えるためだけではない
- 関を通る燐晶の荷は、数こそ変わらないが、年々質が落ちている
- 淵の底の鐘が鳴るのを、聞いた者がいる
- 名送り帳には、ギルドの名簿にない名前が載っている
- 灰山のどこかに、迷宮へ通じる古い坑道がある
- 下灯村の灯が、いっせいに同じ向きへなびく夜がある
- 凪見の湖は、底が知れない
