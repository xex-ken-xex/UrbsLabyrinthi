# Urbs Labyrinthi

## このリポジトリについて

このリポジトリは、実験的なコードを書き溜め、補完していくためのものです。配布、販売、リリースを目的としていません。

公開されている形をとっていても、製品やサービスとして提供するものではありません。動作や内容について、保証やサポートはありません。

ゲーム本体の説明は [`godot/README.md`](godot/README.md) にあります。
